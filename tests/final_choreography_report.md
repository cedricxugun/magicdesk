# 连续开花、星群高潮与高位阀避让 · 1.3.3

## 开花收尾

旧曲线在2.8秒、84%开度减速到0，再启动最后16%的开度，形成可见顿点。新动作保留0.4秒锁止与0.4–0.85秒轻微开缝，随后使用一个连续quintic行程到3.5秒完成。实测2.8秒处速度为0.412747开度/秒，不再中途停止；开度单调、终点正确。

Blender同步只更新20个控制器的50–144帧，中心拆装段保留。六片角度差最大约0.0000168°。报告：`synchronized_petals.json`及`button_hit_validation.json`。

## 飞行星群

使用主过载七秒进度，现有粒子不重置相位、不瞬移；延长寿命并补满12粒，避免高潮时随机消失。

| 时间 | 星群表现 |
| --- | --- |
| 0–1.4秒 | 克制蓄能，速度从1倍增加到1.1倍 |
| 1.4–3.2秒 | 逐渐加速，尾迹延长 |
| 3.2–4秒 | 2.8倍速度、半径共同外扩13%、尾迹1.5秒、亮头1.8倍 |
| 4–7秒 | 连续退潮，恢复原R3轨道尺度与待机速度 |

取消、组装、关闭仍正常淡出。[真实高潮画面](../review/final_star_peak.png)。

## 高位陶瓷柱

原高位Valve0与第2瓣在闭合和展开时相交。现在把整个原尺寸阀门和长供管移到两瓣之间的固定安装线：Godot平移`(+0.26,0,+0.10)`，阀座`(1.15,2.02,0)`、针头`(1.15,2.61,0)`。

11个开合位置对其余69部件均无相交，瓷盘半径仍为0.09。GLB只修改节点平移，几何、纹理、顶点AO的BIN字节保持一致；Blender该部件的位置关键帧与手柄同量移动。报告：`high_valve_relocation.json`、`high_valve_static_candidates.json`。

待机汽源同步到`(1.15,2.62,0)`。保留六条下沿汽源与旋转出生历史，只对高位区域使用逆位移取样并移除原位置的高位蒸汽。缓存内的上下气体没有来源标签，因此高处交汇尾迹采用平滑分区近似；没有重新烘焙流体。真实闭合与开花画面：[闭合](../review/final_closed_clearance.png)、[展开](../review/final_open_clearance.png)。
