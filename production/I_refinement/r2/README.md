# I 气路、压缩与回声源预演 R2

本轮从R1源复制，R1与主I资产不改。当前机械源I_pneumatic_r2.blend、含光效预演的I_echo_r2.blend，以及独立组件I_pneumatic_r2.glb；散列与具体对象名见review/I_refinement/r2/build.json、echo_preview.json。没有替换App里的I，也没有AAA验收。

## 结构修复

初查确认旧连续声道穿过膜片和气囊端盖，尖端套环也碰到活动尾壳。现在采用固定中空芯管、真实侧向进气孔、沿芯管移动的端盖/密封、膜片背面压力杯和对轴的中空连接管。气囊移到较宽的中段，并用三条固定支承连到现有腔体肋。导杆固定，前端盖的套筒滑动，避免压缩时长杆从尾部越伸越远。

膜片悬挂采用三根新弹簧和带外缘固定权重的柔性悬边。弹簧用固定截面相位构建形态键，避免曲线转换时端部滚转造成形态插值缩短；端面按真实座面校准。源动画中气囊压缩0.132模型单位，膜片显示位移为归一化响应×40并限幅0.014；这属于可读性处理，不是实物位移测量。

61个录制时刻检查中，所测芯管/移动端盖、连接管/压力杯与膜片、尾壳/尖端件无面交叉，弹簧端面对位误差约9.3e-8。壁前沿保持在端盖容纳范围内。弹性密封、固定连接套和其他未测金属/外壳组合不在这一项中；不能扩写为整机碰撞认证。

组件GLB确认保留5个带法线的形态目标：气囊Compression、悬边及3弹簧Travel，检查包含稀疏accessor。已在实际Metal中回放气囊、悬边和三根弹簧；8个保存源姿态检查点与Godot矩阵最大误差4.77e-7，见runtime/review.json。它不证明所有连续姿态的逐顶点一致或原生输入。

## 行为模型

app/collection/i_acoustics.gd 使用归一化储气量/体积和阻尼压缩机构，按压蓄压时不提前出波；松手在通道放行后产生一次事件，延迟返回更弱，调频改变回声强弱。喉口关闭时不发波。关闭走单独泄压，停止推动膜片，但保留原振动衰减，等待机构稳定才允许关壳。

它是游戏中的归一化气动/声音映射，非完整声场/FEM。acoustics_qa.json通过蓄压、延迟、相对强度、取消与闭喉检查。pneumatic_take.json包含361帧/30fps的按压、松手、再按、取消、闭喉与收纳记录，驱动新的源动画。

## 专属图集与光效预演

沿用内置image_gen生成的acoustic_atlas_r1.png。I_echo_r2.blend中已有出射弯曲波面、内部导体回程流带及独立局部点光，全部按实际记录事件定时。源版本之后已有独立Godot实时实现，见下节；仍未在日常App接入。图中灰色工作底座与旧按钮仅作源参考，最终依然使用现有公共底座、机械舱罩、全息入口及新I操作匣。

透明PNG的非预乘边缘RGB曾看似大片实心光带，查像素alpha只有约3–5/255。复核改为相机专用实色背景，环境反射不改；不要因此错误增减光场或抹掉透明度。实际射线查证内部导体绝大多数被瓷壳/口板遮挡，return_visibility.json记录路径采样。保留遮挡，改为内部回传提前运行、到达时出现较弱的口部蓝色接收辉光；源I_echo_r2.blend已更新至c3bc77d6...。

## 实际运行时预演

`i_runtime.gd`通过导出的i_runtime_rig.json驱动实际组件形态、六叶虹膜、壳体、端盖与膜片。`i_visuals.gd`和i_acoustic.gdshader使用内置图集，按实际气动事件驱动去程波面、沿真实导体路径的回传流带和到达辉光；图集保留亮度×alpha掩膜与深度测试，不穿过实体。return_schedule提供只读副本，使回传先于到达事件运行，取消立即撤销未来回传。

实际Metal执行361帧，状态与源记录误差约4.9e-15；按压无波、首次松手有去程/返回、第二次取消无迟到返回、静息载体全部释放。runtime_echo/review.json与配对截图记录实际贡献，不是原生控件或最终灯光验收。早期灯光使中心金属过白，分离光照/图集后降低局部灯强度；保留before_light_reduction与light_calibration失败/对照记录。源与实时灯光能量不直接等值，最终材质/照明仍待制作。

新增hardware_shell_check.json在静止/近满压两种状态，分别抽样21档开壳，检查全部IP2网格与气囊壁对前后瓷壳，无抽样面交叉。没有检查包裹关系、旧内金属互碰、完整拆装或连续扫掠，不能说整机无穿帮。
