参考已生成的production/I_refinement/r1/structure_and_motion.png，未重新出图或调用外部API。独立源I_Controls_r1.blend当前21d2291e...，组件I_controls_r1.glb当前039b4b63...；完整散列和命名见build.json。构建器校验已记录源散列并备份，未触碰F/G控制库或共享底座。

五位置顺序为调频轮、单片蓄压板（旁有压力浮标）、连续喉口杆、出/回双簧读数、拆装拨杆。调频采用圆形座，与其他控制器区分；实体轮轴、轴套、滚花、导针孔、旋转轴与轴承、读数导轨均是独立源几何。关闭大盖和机械切换舱罩仍由公共底座提供。

首轮存在轮缘/轴座、主轴/瓷面、导针/后底板相交，clearance_iteration01.json保留失败。补孔与抬升轮沿后，当前源每控件25个姿态下移动件对自身固定件无面交叉；包括压板行程0.015、喉杆绕真实Y轴/0.039支点、服务杆绕0.040支点、双簧浮标与压力浮标。这不证明相邻控件、共享底座、舱罩扫掠或包裹关系无穿帮。

app/collection/i_console.gd已将它们安装到真实共享底座五个home槽位，标签对实际弧面投射；Metal预演截图在review/I_refinement/console_r1/runtime。3252条去重投射射线均命中。压力读数响应归一化压力；双簧分别响应真实出射/返回事件，并采用相同指数衰减与浮标缓动，避免弱返回短到不可读。它仍是独立预演，没有主模块接入、声音、原生鼠标或整机拆装验收。
