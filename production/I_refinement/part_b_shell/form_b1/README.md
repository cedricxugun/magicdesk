# B 外壳形体与分片研究

当前独立源 `blender/collection/I_shell_form_b1.blend`，组件 `app/assets/collection/components/I_shell_form_b1.glb`。它是在真实底座上组合当前A口部的静态形体研究，**不是完整海螺或可交付壳体**。源/组件/检查准确哈希见 `review/I_refinement/part_b_shell/form_b1/checkpoint.json`。

## 当前实际做了什么

A保持原几何，整体统一缩放0.85并按同一装配变换放置。新B以饱满腹部、后方体积和向上回卷收尖构成外轮廓，口部嵌在侧前方。没有复用R7/R8半笼或R16深颈。底座只从原 `helios_model.glb` 提取一份BASE_FIXED；运行检查确认外径仍为2.740000。

闭合总高约3.548场景单位，约1.295D；这只是实际候选测量值，安装姿态/尺度尚未锁定。下方支承目前是占位形体，用于判断空间与落脚关系，不是C的精修结构。

第一轮过早制作内部减料后出现1063条非流形边和错误外部面，已保留失败记录。后续先恢复干净的外形实体，只清出A占用空间。均匀圆柱孔又造成侧面大缺口，因此改为按当前A及18个光学硬件的九个源姿态求保守轴向分层半径；相邻层最大值加间隙构成渐变孔形，补短肩部后，侧面缺口收住。该空间估计不是最终壁厚或连续运动认证。

过强的螺旋起伏看起来像波纹壳，已减弱。表面增加了六个层级的螺旋分片**导线**，因口部开口而分为13段曲线；它们不是13块壳，也不是已切好的六片。实际六片的闭合轮廓、厚度、背部收边和铰链还需制作。

## 可查看的证据

- `views_r4/`：当前真实Metal固定正/侧/背/顶视图、展示角及“仅口部打开、壳体静止”视图。后者不能称壳体ACTIVE。
- `views/`、`views_r3/` 与 `iterations/`：早期水滴形、过强起伏、缺口和失败内部减料记录。
- `fit_check.json`：静止B形体在九个源姿态中未与A内部件或物理投射器测出表面相交；不涵盖壳片运动、内部壁厚、底座支承或体积包含。
- `mouth_clearance_profile.json`：实际三角面的保守分层空间测量，保留源版本、缩放和间隙。
- `B_shell_motion_study_r1.png`：内置生图的闭合/顺序抬起/双连杆细化方向，提示词在PROMPT.md。图略微重画了表面，展开视角也不能证明实际六片数量；以3D和原选图为准。

## 下一项

以当前形体继续校准与原选图的轮廓关系，建立**真正的六片**及连续薄壳，而非继续增加表面导线。须明确背部隐蔽接缝、各片ID、枢轴/成对连杆/止挡，并检查原位、逐片抬起、全开和反向。不要直接把当前实体按随意平面切成六圈，也不要用表面曲线冒充分件。

优先保留可追溯的外表面，按六片的螺旋边界和背部接缝裁片，再制作内壁/收边；当前5.4圈导线参数不等于六个闭合分区，不能直接当分件索引。原动作约定的关闭顺序是**尖端向喉口**，喉闸最后关闭。细化图的CLOSED仅指外壳，喉口沿输入图保持打开以看接口，不替代最终REST的喉闸姿态。

口部模块保持不动，壳片向后方/上方沿螺旋让开，不能再把壳颈转进喉口。C的连续声学内芯与最终支承随后制作；不以当前占位柱/斜杆交付。所有最终动作仍需与已出的设计图和专属资产对应。
