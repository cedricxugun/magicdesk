# B3 六片壳与实体连杆候选

接续 `HANDOFF.md` 顶部。源 `blender/collection/I_shell_linkage_b3.blend`，组件 `app/assets/collection/components/I_shell_linkage_b3.glb`；准确哈希及制作范围见 `review/I_refinement/part_b_shell/linkage_b3/build.json`。本目录内置生图 `B_linkage_detail_r1.png` 与 `PROMPT.md` 只指导双侧叉板、贴合座、贯穿销和两级顶尖载架的外观。图中的数字/数量不能代替三维契约。

## 机构与原有模块

B2 已有六个真正的闭合薄壳网格。B3 以真实内壁确定安装座，在 Blender 增加两侧叉板、带孔衬套、单根贯穿销、止推垫片和凹槽端部紧固件，连接到连续背部承轨。第五片先托着第六片一同让开，之后第六片从第五片载架上展开；关闭反向，喉闸最后关闭。顶尖标记已经跟随第六片。共有六组四杆、十二支双侧叉形连杆，源内有开/停/反向烘焙；Godot 独立驱动按同一几何参数实时求解，壳片始终为刚体。

A口部、完整月光三个乐章、真实五线谱仍保留为独立模块。共享 BASE_FIXED 的尺寸和主 App 注册表没有改。当前运行的 Mac 仍是口部包，B3 没有接入主 App。前支柱和背轨根部为配合研究，**不是 C 连续声学内芯或最终支承**。

## 已查明且保留的失败

- 统一连杆尺寸无法给上部四片完整圆交解。
- 只按单片独立抬起，第五片会碰顶尖；改为两级载架，六片路径通过限定范围壳面检查。
- 从外表面沿径向退固定距离，会把斜壁关节留在壁厚内。改为查询真正内壁，再按面内法线退让整个销座；有限实体检查中大批销轴穿壳消除。
- 首次曲线管帽未焊接，已焊接成闭合实体。
- 原宽支柱挡住下壳；新前侧临时支承仍需与 C 的正式接口一起收敛，不把临时连接当作精修完成。
- 后续有限实体检查还发现顶尖固定板/端帽、第一片固定板和下部相邻叉板干涉；已缩紧顶尖固定座和端部件，第一组机构沿其自身铰轴错层0.020场景单位，保持壳片运动不变，消除相邻叉板相交。各版本/检查在 `review/.../linkage_b3/iterations/`，源备份在 `blender/collection/checkpoints/`。

## 检查入口及边界

`check_i_shell_linkage_b3.py` 检查246个新增实体的闭合性、壳片对实体硬件、固定A对硬件、叉板之间的相交，以及实际源机构端点连接。`i_shell_linkage_b3_qa.gd` 对照真实导入层级与 Blender 烘焙姿态，并检查连杆端点和反向归位。`i_shell_form_b1_review.gd -- --report=.../linkage_b3/build.json` 渲染同一真实底座、固定视图与局部关节图。

几何检查未通过时不得把组件接主 App。端点吻合、姿态吻合、拓扑或哈希通过均不等于美术通过。当前还缺完整硬件两两/体积包含检查、所有A/光学件动态组合、C内芯与正式支承、连续实机演出、入口/切换/操作验证；不称完整I或AAA。
