# R82 · 用户否定 R81 整体外观后的形态重建

2026-09-21 用户明确指出：模型丑、表面有皱褶波纹、连接不精致、开合有的开有的不开，整体像吹风机而非鹦鹉螺。这不是对 R81 局部连接数值的提问。R81 及其普通开合片不能再作为通过的整机视觉基准。

## 已核对的原因

当前 source 的六片外壳里 01/02/06 的旋转角度和抬升均为零，仅 03/04/05 开启。这是旧机构设定留下来的半套开壳表现，不是用户看错，也不应继续拿端点/碰撞测试证明动画合理。侧面近圆平板上划分扇叶、中央红轮毂、前方厚圆筒口和水平向前的体量共同造成吹风机/风扇印象。底部后加的肋板/横梁解决局部接合，却没有与壳形共同设计；曲面皱折和高光断带仍在。

原始建模方法也已核对：`blender/collection/build_i_nautilus_form_r1.py` 的 `point(phi,theta)` 仍用三个椭球半径和扭转角计算表面，再加分片鼓包、布尔切出旧口部。它没有建立实际逐渐增大的盘卷体积。`i_uniform_cowl_loft.py` 又为固定旧圆口把前后截面插值、加局部径向鼓包，再缝接保留截面；后来的法线修正不改变这些真实顶点。因此本轮不再把提高细分或重算法线当整体造型方案，也不将所有可见皱褶武断归因于一个渲染开关。

## 重做范围

回到完整卷壳轮廓与连续表面。参考自然鹦鹉螺的外形关系：偏心、逐渐长大的卷绕体量，凹入的卷心，沿末圈切向形成的口缘。不能只是圆球上雕六条旋线；取消独立突出的大圆筒嘴和风扇式中心徽章。保留《原子之心》方向的奶白釉瓷、镍色金属、温金声学内腔、克制红色操作件。

第一稿采用六段大小渐变的弧形外甲，每段沿卷壳路径分段，而非从中心等分六块扇叶。六段都参加正常开启：微量卸锁后绕各自连续内脊上的短轴掀开，方向随卷壳切线变化；小幅连贯地展开，完成后仍读作卷壳。固定的承力脊与内层腔室明确用金属区分，不伪装成另一半没动的瓷甲。图中数量、动作关系仍须审阅，不把生成图当工程实测。

连接与壳体共同塑形：短、宽、弯曲的金属鞍座从卷壳下方自然收束到原共享接口，内侧真实接骨架；用包覆式轴肩、嵌入式锁扣、实心圆角、层次清楚的配合面表达精工。不沿用外露板材 A 字腿、横杠和长细撑杆的拼装外观。

## 制作次序

1. 内置 image_gen 出整机 REST/ACTIVE 对照与独立开合/鞍座细化图。先视觉检查形态与部件连续性，不依据旧候选自证。
2. 从干净曲面重新建立形体样机；同一真实 BASE_FIXED、固定相机、多视角和同尺寸开合对照。先过剪影、体量和动作，再做微小零件。
3. 曲面采用低复杂度、可控截面和连续切线；在无纹理高光条带/斑马反射下检查真实折痕，再倒角/分件。提高细分数不能替代修正错误截面或拓扑。
4. 每一片外甲有自己的真实关节、轴肩、止挡、锁止和行程，六段动作齐全且连续。检修拆解另做，不能拿半开/漂浮维护态冒充正常演奏。
5. 新形体成立后，再适配三片口闸、读谱光学、月光完整三乐章与音频响应。原功能代码、素材、源文件保留，但不为复用旧大口径而牺牲新外形。

共享底座尺寸、层数、按钮、归档机关和关闭入口继续按原契约；生成图只参考底座外观，不能变更真实 D=2.74 / H=.670608 场景单位。主 App 仍 R68，旧候选全部保留。当前已有独立form_r2形体/开合样机（见README），但未锁定、未完成工艺与原功能、未达 AAA；不再继续 R81 支座细修或 R77 后续拆壳来回避本条。
