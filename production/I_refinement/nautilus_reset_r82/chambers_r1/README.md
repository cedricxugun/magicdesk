## 已确定的下一步

把02–06盖的铰点移到各自外缘，01内卷盖保留R83的轴向退让。几何研究中使用：

- 每盖 `tm=(ta+tb)/2`，新枢轴 `CoilSurface.point(tm, .02, -.023)`。
- 02–06轴保持原切线轴，离座向量 `(0,-.06,0) + CoilSurface.frame(tm).radial*.02`，之后正向45度翻开；先离座、再转动。
- 01用R83/R9的原枢轴、位移和角度。

`chambers_r3/hinge_study/study_release.json`覆盖41个进度姿态的瓷甲互相/瓷甲对新声腔，无该范围相交；**现有执行机构没有按新枢轴重做**。`outer_hinge_release_geometry_only.png`隐藏了不适配的旧执行机构，是明确的几何研究图，不能作为完整模型。此前4姿态研究是假宽松覆盖；加密后发现05/06起步互碰，再加入.02径向释放才消除所查接触。

下一步真正制作外缘短铰座、固定后支撑与移动耳轴，保持闭合外观和全段运动；处理旧导向孔/连接，再做更密集扫掠和实际展示。不能退回小声腔或固定某几片来图省事。还需要改善大空白内壁的结构层次、校准演奏展开与谱面遮挡，保证放大展开仍保持鹦鹉螺身份。

源/组件要按“静态求值网格+保留膜片形态键”的方式导出：只烘焙无形态键物件的修改器，不可全局Apply导致膜片丢失，也不可省略倒角。后续完整拆装、实体控件、正式App与EXE及其他型号全部仍在原目标内。
