## 实际变化

原十二声腔的布局来自 R84 旧开合，继续套在 R88 上会显得太小，留下大片金色空白。现在使用 R88 真正全开姿态和正交展示方向重新排布，保留十二个声腔，以较大主腔和较小间隙声腔形成层次。重建真实开孔、立体镍框、波纹钛膜、金色隆起中心与圆截面导光条。外形、六片瓷甲、铰轴、月光口部和底座没有随布局改动。

沿用 `../chambers_r1/chamber_detail_r1.png` 的工艺与演奏方向，没有重新生成改变整机形体的概念图。规划的可见投影面积指标由 .145 到 .489，只是排布参考，不能当作对概念图的还原度或 AAA 分数。

第一轮大腔只能排下 8 个，随后保留这些主腔，再补 4 个较小声腔。`layout_selected.json` 是精简的实际选择输入；全候选研究数据留本机。r1 的十二内框与内壁存在贴合干涉；r2 调整开孔后仍剩第一框 3 对真实三角接触（双精度分离检查未能将其排除）。r3 只补该处余量，没有退回小声腔，也没有改动原开合来回避它。

构造过程对 657 个非声腔网格的顶点、环顶点索引和闭合世界矩阵作了前后哈希比对，均保持；该项不是所有材质/UV/接口的全字段审计。原功能内芯 GLB 哈希和三乐章音源未改。

## 背面金色碎片：实际是漏光

`rear_ray_probe.json` 对实际 Godot 导入网格射线归属，碎片位置首先命中完整且朝向正确的背板。保留几何、只关声腔局部灯后斑块消失；随后保留光源、将该布局的阴影 normal bias 设为 .005、bias 设为 .01，同一局部斑块也消失。固定 ROI 中暖色像素从 86 到 0，见 `spill_diagnostic.json` 及两个后视对照。

`i_chamber_music_response.gd` 现在接受布局中的可选阴影参数；未配置的旧布局仍使用引擎原值。参数已写入 R88 r4 和新 R89 布局，原声腔导光/能量没有关闭。这不能代替所有光源、视角或透明桌面窗口的验收。
