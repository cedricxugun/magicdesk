## 改了什么

检查 R87 后确认没有遗留的旧后导向法兰，不能凭旧记录臆测删除。新查出的真实问题是闭合时旧 SupportA/B 接到了导套轴线上：原十支滑杆与旧支撑共 11 个对象对相交；R87 原检查没有覆盖这种内部配合。

现在十组固定支撑改成连续成型脚座/支撑/外抱箍，导套内的滑杆通道保留。增加独立黄铜衬套、20 支带实际杆身/内六角的紧固螺钉、真实盲孔和沉台，以及十只可拆导套端盖。所有现有铰轴、短行程、45° 开合和闭合瓷甲保持。背部镍材粗糙度调为 .38，支撑镍材 .30；未改共用底座。

内置订阅生图 `forged_joint_detail_r1.png`、`PROMPT.txt` 和 `art_manifest.json` 已保存。图只作为镍面、倒角、成型脚座的工艺方向；其放大图是简化单轴接头，不能替代实际双导杆/转轴机构。没有用 apilink。
