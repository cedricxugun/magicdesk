# I 回声海螺 · R1

使用订阅内置image_gen生成[结构与动作图](structure_and_motion.png)及[专属光效图集](acoustic_atlas.png)，提示词分别在[prompt.txt](prompt.txt)与[atlas_prompt.txt](atlas_prompt.txt)。原始输出保留在Codex生成目录，项目引用已复制进工作区；没有使用外部图片API或声称可核验的底层模型。

## 图稿采用范围

采用饱满收束螺壳、深共鸣口、六段外壳、导轨/膜片/气囊，以及蓄压→发声→折返→衰减的阶段。图中的底座与切换舱罩仍有漂移，不能据此改共享底座；实际接入沿用现有机械舱罩和右侧全息入口。图上close cap的机械文字不是退出功能的新定义。

六段外壳落实为每段一块活动前壳与一块固定后壳；隐藏背面在图稿中未完整约束，此为明确的装配细化。原I弯管源/GLB保持不动。

## 当前可编辑候选

`blender/collection/I_helix_r1.blend` 与独立 `app/assets/collection/components/I_helix_r1.glb`。结构已有带厚度的螺壳、真实穿孔声板、中空弯曲声道、膜片、带壁厚的气囊、六叶虹膜、共同驱动环和六条销槽。前壳沿导轨略错位打开，源有1/79/157等闭合/打开/返回关键帧。源参考图包含原HELIOS底座和旧圆按钮，只用于尺寸/构图；新I操作匣及公共舱罩/全息器尚未组入源预览，不代表将恢复旧按钮。

源码构建器为build_i_helix_r1.py，新增保护：如果源散列与上次构建记录不符，禁止自动覆盖。若后续手工修改，保留新候选或明确维护补丁，不回到build_models.py整套重建。

## 已纠正的结构问题

- 第一版活塞长度不够，打开后会脱开；已加长真实套筒/活塞并加连接叉，实际网格投影检查五档开度均有有效搭接。
- 扇形叶片产生星状缺口，第一版紧凑壳内覆盖也有漏口。改为按叶片全行程占用空间确定六片轮廓，增加内部滑动腔与工作口遮圈，保留同底座。
- 驱动环0.16rad行程使槽尾局部曲率过小，改为0.30rad；叶片行程仍1.05rad。端部刀具体法线/封闭体已修正，并做圆角槽端。
- 外壳直接径向抬升会互相挤碰，已增加各段沿中心线的错位量；口部坐标系与壳体法向对齐，减少前罩与后壳交叉。

虹膜环驱动的分析参考[UT Austin作者的机构分析](https://cloud.wikis.utexas.edu/wiki/spaces/RMD/pages/51053901/Kinematic%2BAnalysis%2Bof%2BIris%2BMechanism)。本项目轮廓、尺寸和槽线独立求解，没有复制未获授权的第三方代码。

## 实际检查与边界

`review/I_refinement/r1/`包含源渲染closed/open及较近的hero视图，并有structure_check、iris_check、cam_check、shell_clearance报告。当前四项均绑定同一源散列且通过：导轨网格搭接、闭合壳体边拓扑、21档虹膜光口/叶片、41档销槽/固定环、21档异组瓷壳面交叉。各报告只证明所列范围，不等于整个装置无碰撞或AAA完成。旧扇叶、窄壳、过急槽线和径向打开失败记录保留在相应子目录。
