# I 动作与反馈目标

1. 待机：外壳闭合，膜片与气囊静止；无循环强闪光。调频轮/喉杆触发听潮准备，公共旋转始终独立。
2. 蓄压：按住实体压板，气囊有可见有限行程，膜片弹簧逐渐预载，压力读数上升；此时不提前播放出射波。
3. 释放：松手后虹膜按喉口档位放行，气囊回弹、膜片产生衰减振动；专属波前从真实口部向外传播。
4. 折返：延迟后较弱回程沿实际内部声道/导体回到口部，双簧读数区分出射与返回。调频改变响应，而非只改变按钮颜色。
5. 衰减与收纳：压力、膜片、光场分别平息再关壳；再次按压、取消、切换和拆装需要明确过渡，不能瞬间清空或把尚未消退的效果截断。

这是制作合同，尚未全部实施。最终动态不能靠默认粒子/程序圆环替代已生成专属素材，也不能用图稿冒充已运行效果。
