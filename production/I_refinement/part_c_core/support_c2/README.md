# C2 金属承座、支柱与护套候选

当前源 `blender/collection/I_core_support_c2.blend`，组件 `app/assets/collection/components/I_core_support_c2.glb`。准确版本与范围见 `review/I_refinement/part_c_core/support_c2/checkpoint.json`。这是A/B/C组合中的支承候选，**连续内芯还未制作**；主App没有接入，不能称完整I或AAA。

## 已做出的结构

- C1分体夹环围抱A现有后金属法兰，保留A原几何；按真实法兰内缩/倒角校正夹环和紧固耳，真实钻孔、贯穿夹紧螺栓和下半环一体耳轴座。
- C2两组支柱接到夹环耳轴，具有轴承眼、细颈、筒体、膝部叉座/贯穿销、下节套筒、底部叉座与长圆脚座。旧压在瓷壳上的前支柱/临时脚已移除。
- 两条成型穿出口只改B的固定下口沿外套，A瓷壳未改；通道内有金属护套、护口与密封环。不能隐藏外套或把支柱缩成悬空以获得检查通过。
- 长圆脚座按真实BASE_FIXED凸起金属纹饰之间的平面定位；底座的几何、尺寸、控制器都没有改，也没有导出第二份底座。

## 迭代证据

夹环最初前唇撞六根后部立柱，修为按原法兰倒角包覆的前缘；合并夹紧耳后内侧角又侵入法兰，改用真实法兰副本作留量加工，原A不改。均有失败记录。

完整粗杆路径被固定口沿外套挡住，而非所有运动壳片都无法避让。采用真实细颈耳轴接口和成型穿出口后，支柱可以避开运动壳片；第一版护套仍过大，已减薄。原外套从B3继承了30条非流形边和一个微小面，已仅在新C2源中焊接/清理；穿口后的外套仍为一个闭合连通实体。

圆脚盘压住底座上凸出的金属纹饰，不能把D或底座总高当作可放脚的平面。按原BASE_FIXED的实际三角面选脚区，改为径向较窄、沿圆周较长的脚座，再用实际新脚座网格重查。不能复用旧圆形足印的通过/失败结果。

## 当前证据及边界

- `finite_geometry_check.json`：当前338个硬件及固定外套的339项拓扑所查条件通过；21个开/停/反向采样姿态中，壳片对硬件、叉板之间无表面相交。**总结果仍为false**，因为旧 `IB3_RailRootStudy` 仍直接接触 `IAM_RearMountFlange_0074`，需C3补真实耦合接插件。
- `base_fit_check.json`：真实底座D为2.740000，258个实际脚座足印采样最大间隙约1.2e-7，没有非脚座支承件撞底座。仅涵盖脚座/底座配合，不涵盖整套机械牌架、旋转入口与按钮的所有姿态。
- `runtime_pose_check.json`：Godot真实导入层级与Blender792个参考点对照，最大姿态误差约2.59e-6；连杆端点与多次反向归位通过。不是原生交互或完整音乐验收。
- `views/`：同一真实底座的REST、开合静帧、侧/背和局部图；`mount_isolation_rear` 明确隐藏B壳/背轨，仅保留A和C承座/支柱，且增加一盏局部检查灯，不能冒充完整OPEN或全局照明验收。

没有全硬件两两/体积包含检查、完整A/光学动态组合、连续原生演出或最终材质验收。整机看支柱仍偏细，须结合C3大体量和目标图继续调整外露套筒与叉座，保留已校准的接口和穿套段。
