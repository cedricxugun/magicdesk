本轮先用内置 image_gen 补出 `suspension_motion_r1.png`：REST、LOAD、REBOUND、SETTLE，明确前压座随膜片、后座固定、柔性悬边内动外定。提示词在PROMPT.md。图仅是局部动作/工艺方向，不是尺寸、用户验收或完整海螺。

## 已制作的独立源

`I_diaphragm_response.blend / GLB` 从 `I_mouth_finish` 保留源派生。现有膜片及轴向触须共用 IAM_DiaphragmMotion，最大源行程±0.006场景单位。旧三根静态曲线弹簧替换为有真实截面的闭合网格，前/后杯口连接、前压力连接柱按膜片实际表面射线落点制作。

弹簧保留线径与卷径，通过专门Pressure/Rebound形变键改变节距；后端保持固定，前端匹配随动压座。柔性悬边沿半径分配位移，外圈固定。源保存完整薄片形变键；导出时仅在内存中移除已有大体量薄片键，薄片仍走完整拓扑/原始场数据，保留四个悬架网格的独立形变键。不得把导出后被移除键的内存状态再次保存成Blender源。

独立运行驱动 `app/collection/i_diaphragm_response.gd`：加载、释放冲量、阻尼回弹与quiet取消，以小步积分保持一致。quiet停止接收新激励并平滑消散，不瞬移。不是完整声学物理仿真，也还未接真实声音、现有音乐或主App实体控件。

## 检查与限制

- build.json 位于 review/I_refinement/part_a_mouth/shutter_r2/diaphragm/，包含源/组件哈希、形变网格、端点/压座和源示范动画。
- suspension_check.json：九个独立悬架行程，弹簧端点对压座、变形自表面、随动结构对固定结构检查。闭合薄片状态；不代替全开合×膜片运动组合扫掠。
- 原始接触记录保留：弹簧固定端与后压座、柔性悬边与固定圈为设计配合，须对照端点间隙/固定边约束，不能粗暴把所有相交都删掉或宣称零接触。
- response_qa.json：导入形变键存在、30/60/144Hz加载、释放、再次加载、quiet中途取消、晚到激励拒绝及最终归位。它不验证音频、原生输入或全部源/运行时网格位置等价。
- runtime/：实际Metal静止/受压/反弹，两侧及无外罩诊断。早期杯口与座体外圆共面闪斑已改为端面对接。
- motion/：带源版本的5.5秒侧面机构诊断。外罩和护网明确隐藏来观察联动，不能称完整App打开动画或检修演出。

此版本尚未替换用户收到的777613d0包/日常App。继续完整动作组合与动态端点/连接检查、正常正面可读性、膜片/音叉和声场的先后响应，再A美术收敛与B螺壳/C内芯/完整海螺及月光模块。旧i_acoustics.gd仍包含被弃用的六叶开口面积公式；接回前必须按真实三片开口更新，不能不经核对直接绑定。
