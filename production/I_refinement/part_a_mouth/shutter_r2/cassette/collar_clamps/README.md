# 喉口卡扣、贴合压脚与后方拉杆

当前为独立 **I_collar_clamps** 候选，源 `734f5365…`、组件 `9e57f33f…`，准确哈希见 `review/I_refinement/part_a_mouth/shutter_r2/collar_clamps/checkpoint.json`。用户当前打开的 e54f5593 App 仍使用 I_diaphragm_response，本轮没有替换它。

## 构造与方向

保留原六个角位置和共同底座。原平面小卡扣替换为：贴合瓷面的薄垫片、镍色压脚、两块平整的承压面、偏心轮及收窄带弧度的红色握柄、贯穿瓷壳衬套的连续拉杆、后方承座和垫片螺母。后方承环增加与本体合为一体的耳座。

拉杆半径位置为喉口局部0.838；衬孔半径0.00425、销轴半径0.0026、对应轴孔半径0.0029。所有数值都是实际3D场景单位，不是毫米。锁柄沿圆周方向布置，横轴沿局部径向；Blender枢轴基准Z旋转90度，服务松开量驱动局部Y轴至65度。Godot按导入后的局部轴和原基准姿态驱动，没有另造一个轴心。

偏心轮压住承压面，中央拉杆连接后方承座。该形式参考了[带拉杆及承压片的偏心夹紧结构](https://www.elesa-ganter.com/en/www/clamping-levers--clamping-levers-with-eccentrical-cam--gn-927v2-b)的工作关系；本项目只是视觉机构模型，没有做实际夹紧力/强度认证。松开是维护动作，不是音乐喉闸的开关；暂未接入App维护控件。

## 已纠正的问题

最初向内布置的0.824拉杆衬套碰到了内衬，实测后外移并补后方耳座。第一版均匀采样的垫片虽在顶点贴合，三角面之间仍与瓷壳相交；现直接裁切**打孔后的真实瓷壳三角面**，排除盲孔底面，再生成闭合厚度，保留极小数值间隙。

另外修正了定位销与头部的间隙、后垫片对衬套的孔径、销轴端盖的真实内孔。第一组近景有反光三角斑、握柄偏方，已修硬边/加权法线，收窄和弯曲握柄，压脚复用既有内置生图镍拉丝微法线。旧版本记录保留在 review 的 `iterations/` 和 `runtime/`；当前实渲用 `runtime_r4/`。
