# R60 桌面灯光与真实谱面采样

本轮沿用 R59 主 App 组合、R55 身体、原 A、R40 导光与 R43 镜片/谱面安装。未改变底座、口部连接、壳体几何、真实刻谱 PNG 或音源。全目标 active，无新安装包。

## 已采用

主 App I 独立照明配置：三面光20/24/4，环境.42，HDR反射能量.30，SSAO半径.08/强度.55，SSIL半径.30。保持瓷壳亮度，减轻原先偏重的接缝暗影。照明控制器完整记录/恢复环境、HDR能量、辉光参数与各灯能量/尺寸，含中途反向切换；B/F/G原值保留。

谱面换用 app/assets/collection/art/I/desktop_optics_r60/score_layout.json，实际光学几何与全部乐谱不变，细笔画coverage gain1.35，空白仍透明。shader在fract之前求坐标梯度，再使用textureGrad，避免贴图边界选择错误模糊级别。依据 Godot 官方文档：https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/shader_functions.html#texturegrad 。实际独立GPU样本验证其效果，不能只以公式推断成功。

## 不采用的尝试

- 全曲142张刻谱图的alpha范围显示，一些高低音/连线已接近上下边缘；裁留白只能安全放大约0–3%，不能统一大幅裁剪。保留原尺寸和完整内容。score_bounds.json仅测量，不是裁图资产。
- 首轮面光12/14/3、HDR.20令瓷壳偏灰，不采用；take_r1保留，含试验性Softlight辉光。
- 第二轮校准了实际加法辉光枚举，但独立开关对比显示辉光主要加强右上瓷壳高光，不改善预期导光边缘；最终I配置glow_enabled=false。不要把试验图的glow开关说成最终采用。

## 实际证据

- take_r2/take_r3：实际main render_view，同一暂停姿态/相机/真实谱位置的照明和笔画对比。take_r3的06_glow_off、09_local_spill_on与10/11近景解释各参数的实际作用。相机近景仅诊断，未替换主App相机。部分试验图开启了最终未采用的辉光，当前默认以main_regression为准。
- take_r3/pixel_ab.json：局部12灯开关改变23,097个可见像素，说明邻近金属实际接受照明；全屏辉光作用位置另有记录。数字不代表美术验收。
- sampling：真实staff shader及原始谱片，192×128、7种源片边界偏移，单独比较隐式采样/显式梯度/覆盖率。2种偏移旧路径出现179像素竖向模糊带，显式梯度清除；其余5种无差异，不能宣称任何位置均有大改善。coverage仅增强既有笔画覆盖率；原来量化为0的少数极弱边缘最多变为1/255，不产生矩形黑底。
- lighting_qa.json：I/B/F/G中断混合与重新采集的实际Environment/HDR/灯光状态精确恢复；还测试了未默认采用的辉光淡入模式切换。已有F/G照明回归也通过。
- main_regression：本轮默认配置的B→I→B、音乐启动/收谱/停止、反向/取消预热、原材质恢复、同底座/相机及B照明恢复。以完成后的report及日志为准。
- R59_native_shutdown_receipt：本轮通过CUA Cmd-Q关闭上一版主App，实际收谱合壳至shutdown_final、进程退出0、无资源残留警告。范围是上一版从暂停状态正常退出，不等于本轮新包退出或全工况。
