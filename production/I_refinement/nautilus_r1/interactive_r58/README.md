# R58 当前海螺交互开发预览

本轮沿用 R55 身体、原 A 口部、三镜片和全透明居中谱面，新增可复用的上部组合与开合顺序控制。主 App 的旧 I 注册项尚未替换，没有新安装包。

## 使用

在仓库执行 `./tools/run_nautilus_preview.sh`，使用本机 Godot 与默认音频输出，初始关闭且停止。M 播放/暂停，点击谱面或发射器播放/暂停；Space 或点击口沿开合；拖动旋转、滚动缩放、R 复位、X 停止。实体底座按钮和共用切换入口尚未在此独立预览接线。

## 实现

- `i_nautilus_assembly.gd` 组合当前身体、A、实际口部响应、十二腔室响应、月光与谱面；不持有底座和窗口。
- `i_nautilus_sequence.gd` 保证喉口先开、外盖再开、最后出谱和播放；关闭先停止音乐并收谱、再收盖、最后合口，支持中途反向。
- 预览使用当前材质与工作室灯光，恢复正常不透明窗口以避免继承桌面透明窗设置造成白底/说明消失。谱面自身仍全透明，禁止黑底。
- 音乐 manifest 可由当前组合指定，使用真实录音频带。支持内嵌 mouth_spec，避免将来打包硬依赖外部 review 路径。
- 窗口关闭先释放声音再退出。

## 已检查与范围

证据在 `review/I_refinement/nautilus_r1/interactive_r58/`。

`assembly_qa.json`：当前真实组合的开合顺序、暂停冻结、恢复、收谱、反向、取消播放/蓄压、释放通过；内嵌 mouth_spec 分支也通过。

`os_input/01..09`：原生 M 播放，点击谱面暂停/恢复，拖动旋转不暂停，Space 反向、完全关闭、点击口沿开启、播放中关闭窗口。原生输入后读取实际状态，不以脚本注入代替鼠标/键盘。`native_exit.json` 记录进程退出码 0、进程消失，日志无 Ogg/ObjectDB 资源残留警告。

原生预览自然接续第一、二、三乐章，最终达到 961.036 秒并进入 ended；第一乐章中有一次明确的人工暂停/恢复测试，不能称整曲无间断试听。`full_work_native/watch.json` 仅连续监测第三乐章后段到结束，前两个乐章通过独立观测记录。所有此轮原生 QA 使用 Dummy 音频驱动，证明运行时和输入状态，不证明扬声器输出无爆音/断音。谱时仍 estimated_requires_musical_review，不声称逐音准确。

## 用户音乐停顿反馈

旧 25 秒视频在第 15 秒人工暂停、第 17 秒恢复；正常演示与测试现已分离。`--music-review` 连续播放，只有 `--test-pause-resume` 才插入暂停。R56 连续 63 秒视频的原停顿窗口与源音频一致，见上一轮验证。不能把旧测试片作为正常播放表现，也不能据此断言用户旧 App 的所有可能断音原因均已排除。
