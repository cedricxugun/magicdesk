## 真正的固定关系

03导向总成的后脚座与后壳通过两组BodyBolt固定。孔衬、内压片、内螺纹嵌件属于后壳；外垫片随螺栓。导向总成包含25个实际网格，后壳与六个内件共7个，另有4个螺栓/外垫片网格。

完整拔出螺栓 .07 再横移的旧路径失败，螺杆和垫片会穿过两侧导向套。当前先沿真实孔轴退 .010：独立网格极值证明两根端部越过内嵌件约 .00399975/.00399992，仍有 .01987/.02031 保持在孔衬内。随后导向总成沿后脚座外法向离座 .8，螺栓也随总成移动。没有假称新增了防脱螺栓锁环；实际细螺纹仍是简化结构，扭矩/重力不是本次检查范围。

## 后壳路径

沿脚座法向直接外移先撞04固定后壳，更多直线方向也失败。偏下方向能先脱离04，却在末端撞共同安装座；所有失败保留在partial_bolts_r3/route_r4。

当前two_stage_r5先沿 **normalize(normal + hinge_axis*.7)×.12** 退出，再沿 Blender世界Y **+.8** 向后展开。两段之间保留停顿。首段的实际偏移约(.03008,.03995,-.10908)。原壳和保留衬件整体移动，没有切掉边沿。

404个记录由4个阶段×101位置构成，其中阶段1是保留兼容旧分段的静止保持，**实际移动阶段为303个采样位置**。每个位置对真实固定体和所有本轮运动组相互检查，当前无三角面接触。非连续碰撞/包含/完整准备动作证明，也不能证明后续02壳一定可拆。
