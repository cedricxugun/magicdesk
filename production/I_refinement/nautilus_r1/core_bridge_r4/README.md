## 当前限制和检查

`topology_check.json` 检查真实 BodyRoot 下所有网格，包含新 IC1/IN3；`cover_sweep_check.json` 也检查该层级中的新固定件。只按 IN1/IN2 前缀的旧检查不能覆盖新内衬。

`core_contacts.json` 分开列出 A 两个源姿态、后法兰紧固件及尚未完成的腔室连接。只有经实网格证明的销端盖/垫圈座合会分类；其余相交均保留。

`receiver_wall_check.json` 检查接收槽实际内三角面中心和边中点至实际外表面的距离，使用场景单位，不能冒充毫米或连续体积/强度证明。基线 d84b7d87 也查到约 0.0012 的过薄区，因此不能仅排除本轮新槽后宣布壁厚通过。

当前仍在复核后法兰、接收槽和壁厚。旧腔室/支筋有分离网格岛及与新内衬相交的末端，**真实承座、膜片边框捕获、到底座的连续承力路径还未完成**。不能只改名称或删除零件刷绿。上方三片的实体升降/转轴也尚未按新形体配装；完整演出、谱面斜角可读性、材质和原生验证继续待办。

`core_bridge_isolation_front/side` 隐藏 A、外壳与旧腔室，只看新内衬/卡箍；不是整机、不是实物展开图。完整组合用 `relation_rest/open`。
