# R65 安装座、支柱与穿口的释放顺序诊断

可靠主体仍R61/0ba13905；R63的03号动画、R60光谱与R62入口不变。本轮是源结构/路径诊断及实际姿态检查，**未接主App、未产出可采用的新整机源或完整拆解动画**。全目标active。

## 实际进展

直接把01/02壳板、穿口和两根支柱一同翻离，虽然保持了组内连接，却会穿过口部、内芯和06壳片，cradle_probe.json完整记录，不能采用。

可继续推进的分层方向在 `lifted_legs_r2/probe.json`：

1. 底脚螺钉上退，侧向暂存；上耳轴端盖先退出，向同侧拔出的销轴前方端盖随之继续移动，避免销轴追上暂存端盖。
2. 完整安装座——DeckFoot、LowSaddle和四组拟合座/垫——留在真实共同底座上，上部组件升离.45。只留DeckFoot会拆开原有LowSaddle/DeckFoot接合，所以已否定该旧方案，保留整个安装座。
3. 两根支柱连同其底脚小总成沿各自真实轴线下移.25，穿口内衬/密封仍留在壳板上。此层级无需先拆开合并的FootPin端帽：脚销保持在支柱/脚座小总成内部，不能把这解释为脚销已经可独立拆卸。
4. 支柱离开后，再让两组穿口沿各自轴线退出.22。

上部升离、螺钉侧向暂存、支柱退出的当前采样无检出的接触。第二穿口也在所查位置无接触；第一穿口于约10%行程仍擦到02壳板，46对三角面。尚缺完整组合时间线中所有暂存件相互及升离过程的统一扫掠，不能把分段采样当整段动画通过。

## 第一穿口内衬为何仍未通过

`port_escape/`试图只对 `IS18_Leg01_PortLiner` 的内侧让位，保持01/02壳板和外侧384条表面射线。原件有8对BVH自接触，不能因初始装配通过就假定该零件自身干净。

- 多次差集产生了第二个薄碎片；单次合并工具仍留薄碎片和自接触。
- 加.00015轴向工具余量后恢复单体，但仍有5对接触，其中2对是几何完全相同的旧接触，其余部分属于新三角化后的近擦接触；没有把它们自动当作通过。
- 相邻短边的有界清理最终能把累计顶点变化控制在1.5e−7内，但随后拓扑不再通过。不能继续扩大焊接范围或删除可见片段刷绿。

**该候选从未通过保存门槛，没有可采用的新blend/GLB。** `build_check.json`可能保留的是失败前一轮诊断；最新失败看port-bounded日志，不能按文件存在判定通过。

下一步应以真实壳面和现有孔轴重建一体、可退出的内衬/法兰，保留真实内孔、必要壁厚、贴合和外形工艺。不要仅反复对旧叠层薄裙边做布尔裁切。新件必须重新验证自体、与01/02壳板、支柱/密封的配合与完整退出；之后再拆02壳并解决R64夹环销的访问空间。
