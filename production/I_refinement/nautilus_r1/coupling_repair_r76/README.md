## 实体变化

`blender/collection/I_nautilus_coupling_r76.blend`（31a7b616）由R73衍生。六个原孔的圆柱壁被连续攻牙壁替代，复用原边界顶点，避免R75布尔并集留下破面。螺距.0006、径向间隙.00003均为原安装父级单位，源并未定义毫米。实际安装含约.7缩放，退出世界距离.006。

旧上夹环3415多边形有一条三角化长边跳过近共线边点，保留全部原顶点重分三片后，原始世界三角自接触归零；顶点位移0，采样表面差约6.01e-8局部单位。不是删掉接触面或放宽容差。八个改动网格闭合、正体积、自接触0，原其它1229个网格的几何/法线/UV/形变/变换/材质槽保持。此前怀疑female站位重复，诊断没有支持，未采用该解释。

六螺钉独立各121位置检查正确螺旋退出；故意只平移四分之一螺距或只扭转四分之一圈均发生明显干涉，确认真实螺纹嵌合。另有81松脱+81整嘴退出位置，包含固定件、已暂存前序部件及原底座，所查三角相交为0。这些是有限位置几何检查，不证明连续碰撞、扭矩或制造强度。

## 先图稿再动画

`release_storyboard.png`来自订阅内置生图，提示词在PROMPT.txt。采用旋松→短停→初始脱离→平稳抽出→沿原轴回装的节奏，以及克制的陶瓷/金属工艺方向。图中螺钉特写错指成外圈卡扣，整嘴箭头又可能误导为旋转，这两项不采用；真实轴线/几何/位置以源模型为准。图稿不是已实现材质截图。

Blender专用动画源 `blender/collection/I_coupling_motion_r76.blend`（ac086bd3）包含13组/491真实网格：完整口部、六螺钉、六垫片。0.5–2.9秒旋松；3.25–3.85秒先沿轴退出.035，再至5.75秒完成余下.765行程。螺钉按真实螺距推进，垫片仅平移，口部不转。Blender完整往返13.4秒；运行forward clip6.4秒按60fps导出385键/通道，26位置/四元数通道。

专用源已摆入支柱/穿口、03前后部退出后的准备态，只用于这段动画创作，**不可替代普通主体源重新导出**。Godot接收实际求值的标志点动画，不用程序轨迹冒充Blender动画。独立review驱动支持限速反向、中断、精确恢复局部变换，主App还未接完整检修。
