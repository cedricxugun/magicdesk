从R19三组导向机构派生27件：密闭缸体、活塞/杆、活塞密封、前端导封、止推垫圈和法兰安装螺钉。杆随既有滑架沿真实导向轴抬升。只加工三组既有后块/滑架，其他源网格与变换保持；A、壳体连接、12组内腔承座、低支承、真实HELIOS底座未移位。

首版88454e7e因曲背梁进入缸体/活塞空间、法兰垫圈压入过渡肩而失败，已保存到iterations和checkpoints。当前缸体有实际背梁通道，两侧承力翼仍与后块连为一体；安装孔圈外移至可容纳的法兰区，并加工平座。不能将首版失败报告复用为当前证据。

内部接触、9姿态外部扫掠、实际渲染三角、源保护和5832个Godot导入变换见证点通过各自范围。真实网格射线测得活塞首尾余程与缸壁/密封/导杆间隙，缸体、活塞杆、后块及滑架均仍为单连通实体。检查不证明真实压力密封、载荷、连续全场景或AAA质量。
