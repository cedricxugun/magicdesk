# R59 当前海螺接入主 App 开发路径

本轮为实际进展：新增专用组合适配，实际主场景渲染和原生鼠标测试后，仅将默认 registry 的 I 行切到当前 R55 组合。旧 I 行保存在 review 同目录 previous_I_registry.json，旧源没有覆盖。无新安装包、无 Git 推送；AAA 与全队列保持 active。

## 运行

`./tools/run_nautilus_collection_preview.sh` 使用真实主 App、共用底座、机械牌架和右侧全息旋转入口，自动选入当前 I。默认平台音频。当前已打开的测试窗口保留展开且暂停。

左侧黑色拨钮播放/暂停月光；旁边压板蓄压回声；中间旋钮调音量；仪表显示声学响应；右侧黑色拨钮展壳/收拢。模型旋转使用右侧全息入口，牌架仍由左前奶白舱罩打开。完整拆解功能仍待制作，不能把展壳声称为拆解完成。菜单动作文本已相应区分。

## 实现与修正

- 专用 i_nautilus_module/play/effect_bridge 接口复用 collection.service，保留专用口部、十二腔室、谱面、录音控制。只创建一个整体拾取体，不生成上千个细节三角碰撞体。
- 清单只复制真实运行时绑定、内嵌 mouth_spec，生成脚本 tools/build_i_nautilus_manifest.py；主组件与 A 组件 SHA 仍校验。
- 使用既有 archive_atlas/ghost 素材完成模型回收与重建。切换时已停止音乐并完成收谱、合壳；临时扫描着色结束后逐项恢复原始材质对象。临时 StandardMaterial 转换尚不是完整材质等价转换，不能称切换美术已最终验收。
- R1 发现从预热场景 reparent 到主场景触发 _exit_tree，误删镜片/光学附件/回声灯。新增明确的 transfer_to 生命周期边界，仅迁移时保留附件，真实销毁仍清理。
- 主相机不改，整台上部装置增加 .45 弧度初始展示朝向，让口部五线谱面向视线。底座未缩放/旋转，A 与身体局部关系不变。展示旋转可单独开启，音乐不随之暂停。
- 单次回声动作有 .8 秒可见蓄压；关闭/取消清掉待执行压力。持续压板仍按按住/松手控制。
