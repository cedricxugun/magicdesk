# 圆卷声学腔与前甲开启修订

2026-09-13。本轮继续解决新鹦鹉螺展开后偏空、瓷甲过于均匀的问题；不是主 App 或最终艺术验收。

## 设计与源

[腔室及音乐响应图](chambers_and_response_r1.png) 来自 **built-in image_gen**，[原提示词](PROMPT.txt)、[来源清单](art_manifest.json) 已保存。它规定成型青铜腔室、镍质包边、深色折纹膜片和沿连接通路传播的金光。图中的音乐状态喉片仍画错，不能据此改回关闭喉片；五线谱按用户最新要求保持口部居中。

源仍在 `blender/collection/I_nautilus_form_r1.blend`，由版本检查保护并保存旧源；新的整机源/组件哈希以 `review/I_refinement/nautilus_r1/build.json` 为准。

已将外甲改为不等角度、不等饱满度的卷室，加入连续深层内衬、12 组成型弧框/折纹膜片、实体通风孔、支承筋和沿腔室包边的金属管。膜片后方有连续内衬，框架不再只是几根细线。实际图在 `review/I_refinement/nautilus_r1/views/`。

## 开启方式的重要纠正

首轮整片瓷甲从前面绕到背面，绕单根后侧轴转动会让背沿侵入内腔；加大角度也使第一片扫入喉口。这是机构分件问题，不能靠特效遮盖或继续调一个角度解决。

现在口部附近两块为固定包覆，其余四块采用固定背壳和独立前甲。前甲先沿前方/径向抬离，再绕外沿轴转动，返回时反序。当前升降/铰轴仍是用于确定空间路径的机构候选，实际导轨、联杆、止挡和固定承座尚未完成；图中单独的铰轴筒也不是成品关节。

`i_nautilus_form_driver.gd` 已支持对应分段路径。源码里的 `lift_fraction`、位移与角度来自实际 3D 候选，不是生图数字。基座和 A 的整体位置本轮保持不变，音乐谱带仍随整个口部变换。

## 修复与检查的范围

- 已修曲线转网格的端盖分离：原端盖与管身有重合但未焊合的环，现为实网格焊合。
- 连续内衬用周期网格连接背缝，避免完整圆周重复封边造成非流形。
- 安装孔此前无必要地延伸到背壳并打出小口，现为覆盖实际 A 包络的盲腔。
- 穿过口部安装腔的个别腔室/支筋改为在完整的允许区域终止，去掉被裁切后悬空的小残片；不是隐藏必要的承力连接。
- 保留拓扑失败和扫掠失败记录。`topology_check.json` 只说明命名源网格的连通/闭合/微小面情况；`cover_sweep_check.json` 只检查 9 个实际求值的机构姿态，对比新固定件、其余外甲和源 A 第 181 帧，不是全部 A/光学/底座/连续体积检查。
- 首次扫掠因 Blender 源 F-curves 恢复姿态而被断言拦下；检查脚本现在仅在加载后的临时场景中清除外甲动作，再验证求值后的实际矩阵，不改源文件。

`acoustic_core_isolation.png` 隐藏瓷甲、背瓷壳与对应包边并靠近相机，专供内腔检查；它不是完整 OPEN 或拆解演出。完整状态请看 `linkage_open_100.png`。
