# 腔室框架、膜片与内衬的实际夹座

从 R8 `69b82a67…` 派生，当前先完成01腔室的四个安装点，验证后继续其余腔室。R8仍是已记录的接续基线，R9候选需要看当前 `build.json` 和检查，不因文件生成便视为通过。

2026-09-14 已记录的首组来源为 `8cd56f53…`，组件 `2c4e4128…`，见 `checkpoint.json`。四组夹座、八支实际螺钉通过新/修改件拓扑、完整新夹座接触复核和盲孔检查；9个外甲姿态所查项也通过。此结果不覆盖剩余腔室、完整膜片边缘压圈、底座承力和最终美术。后续五个腔室正在独立R10候选中推广，R9已验证源保留。

设计依据为 `../core_bridge_r4/throat_connection_sections_r1.png` 的腔室承座局部。夹座由上压块、下支座、贯穿螺钉和垫圈组成，分别贴合框架、膜片两面和连续内衬。螺钉进入内衬盲孔；盲孔底和剩余厚度在实际加工后的网格上检查。

安装点按实际螺旋边框方向建立局部坐标，避开框架侧壁、通风孔和弹性窗口。曲面截取需要完整足印覆盖，并在裁切后的区域检查可见表面。不会把侧面或被遮住的另一层误认成夹持面。

上下表面的真实三角边共同约束一份平面分网，再从各自实际面恢复高度，形成上下共用拓扑的实体。不能直接拼接有T形接缝的交集三角形。打孔前固定框架、膜片、内衬的原三角面及法线；打孔后检查实体非空、闭合、实际接触和盲孔。

边界必须使用同一份原始足印轮廓，并保留高度变化节点。用带浮点扰动的裁切边界重算凸包，会把本应共线的点变成很窄的二维三角形；抬升到三维后，它们会成为错误的竖向面。当前保留原始面方程，统一边界，并对实际面高度误差检查，而非仅核对顶点。

入口：`tools/geometry/plan_i_chamber_seats_r9.py`、`blender/collection/i_fitted_laminate.py`、`build_i_chamber_seats_r9.py`。候选位置和失败原因在 `review/I_refinement/nautilus_r1/chamber_seats_r9/layout_candidates.json`，不是一份完成报告。

此前手工交集分网的T形接缝、侧面误选和布尔碎面试验保留。若检查发现空零件或非流形，不得用开合检查绿色结果覆盖它们。01旧深支筋只在新夹座实际建立后作为被替代构件移除；连续膜片边缘压圈、后续腔室及到底座的承力收尾仍未完成。
