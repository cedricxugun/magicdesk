## 制作与验证

沿用 [腔室及音乐响应设计](../chambers_r1/chambers_and_response_r1.png)、R35内置生成的专属光纹及其提示词，本轮没有新增生图或外部API。原静态模型的坐标、实际渲染三角、法线和变换保持，只新增膜片形变键。

原始最近顶点距离不能覆盖长三角面内部与夹座的关系。首版因此碰到夹座；后来将实际夹持件包围范围涉及的整个膜片面固定，并以沿网格的距离平滑权重。喉口裁切端面的法线不一定径向，必须按源core_termination裁切深度及非弹性端面归属固定。失败源5646022b、5902827b、6854fd2b和报告在iterations/checkpoints留档，不复用其通过状态。

当前在源帧1（闭合）和217（开盖/A响应状态）的实际求值周围几何上，检查了零位、正负极限、正负半程及交错极限：没有新增膜片自接触、夹具接触或膜片间接触；固定顶点完全不动。**第七片原有3对基线自接触仍保留，未在本轮修复。** 不把“无新增”写成整机完全没有自接触。
