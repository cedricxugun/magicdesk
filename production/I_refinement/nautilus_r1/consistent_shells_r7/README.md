# 接收壳与相邻瓷甲的统一壁面

当前候选从已建立后法兰的 `core_bridge_r4` 派生。制作源为 `blender/collection/I_nautilus_consistent_shells_r7.blend`，精确源/组件版本及检查读 `review/I_refinement/nautilus_r1/consistent_shells_r7/build.json`。不代表 I 完成，不替换 App。

## 最终采用的方法

先固定原始外表面的真实三角面，再生成向内的实体壁。用每个源顶点的显式编号和整层连通关系区分内外两侧，恢复外侧的原坐标与原始角点法线。逐个核对三角面的数量、朝向和顶点坐标，不能只比顶点集合；非平面四边面换一条对角线，就会改变真实曲面。

所有相邻瓷甲使用同一规则，避免新内壁与邻片的旧厚壁相挤。02 的口后下方按实际薄弱点增加内侧厚度，形成加强区域。A 口部的安装、所有金属件与真实共享底座保持来源不变；实际开合、相邻间隙和壁厚仍须以报告及渲染确认。

实现入口为 `blender/collection/build_i_nautilus_consistent_shells_r7.py` 和 `i_native_receiver_shell.py`。外表面的精确来源证明使用有方向的三角面计数与原坐标，BVH 距离只作为交叉诊断；极细三角面可能使浮点最近距离不稳定。

Blender 的壁厚工具也存在局限，名义厚度不等于实际处处满足要求；采用后仍检查真实面间距。[官方说明](https://docs.blender.org/manual/id/4.5/modeling/modifiers/generate/solidify.html)

## 已弃用的内壁尝试

- `core_bridge_r4` 中的整体最近点投影会留下跨过凹曲面的长边；0e1193ca 的后法兰零件可以作为来源，02 内壁不能作为最终结果。
- `receiver_fit_r5` 的多块布尔加强保住了外表面，但留下大量非流形边，不能沿其绿色外形报告打包。
- 未先固定三角面的壁厚试验会重分割原四边面；顶点看似相同也不意味着外形相同。
- 逐顶点选最近的生成副本可能混淆内外层；现按源编号和整层连通关系确定。

以上失败源和诊断保留供追溯，不作为当前完成证据。
