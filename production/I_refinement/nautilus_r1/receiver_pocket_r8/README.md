## 不作为接续主体的试验

- R4 的内壁最近点投影会产生跨过凹曲面的长边，不能用顶点间距代替整个面间距。
- R5 多块加强体的布尔叠加留下了非流形边，不能沿外形通过结果打包。
- R6/R7 的全壁生成仍有接缝、局部厚度或邻件配合问题，尚未替换本候选。保留它们作为结构收尾试验。

薄区要结合真实承座、加强结构和最终材料继续收尾。下一步先处理旧腔室末端与连续内衬的实际连接，避免工作停留在反复调整单一厚度指标。

## 制作方法补充

先固定真实三角面再修改/导出。非平面四边面换对角线，即使顶点相同也会改变曲面。内外壁标记必须写到所有新顶点；生成副本要按源编号和整层连通关系确定，不能逐点选最近副本。外表面应同时检查实际三角面、位置和法线。

相交检查使用 Blender 的三角面回调；壁厚检查在真实三角面上计算点面和边边最短距离，仍不等于载荷或全动作证明。[Blender 实现](https://raw.githubusercontent.com/blender/blender/main/source/blender/python/mathutils/mathutils_bvhtree.cc)

`receiver_inner_inspection` 只显示单片内侧并有检查灯；`core_bridge_isolation_*` 隐藏 A、外壳与旧腔室。完整组合看 `relation_rest/open`，不能拿独立检查图冒充整机完成画面。
