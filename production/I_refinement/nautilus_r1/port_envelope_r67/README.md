# R66/R67 第一穿口内衬：配合重建与可见面候选

可靠主 App 仍是 R61 / 0ba13905。以下均为独立候选；没有更换 registry、没有新安装包。R60 灯光与透明谱面、R62 共用入口、完整月光及全模型队列保持。

## 由实际失败定位问题

R66 `f2dc273d` 重建为规则闭合环形网格，自接触为 0，但装回壳板有 428 对三角面接触。外侧384条测量接近原表面不能证明整个配合正确。`port_rebuild_r66/contact_regions.json` 显示冲突跨返面多个环，并包含 02 交界的正面；不能只改一处法线。

R67 导出实际皮壳三角面，在二维交叠多边形所有顶点建立返面高度约束，使线性三角形位于真实皮壳外侧至少 .0004。孔轴、内孔 .0295、沉孔 .0306、管身与共同底座保持。对应脚本：

- `blender/collection/export_i_port_height_r67.py`
- `tools/geometry/solve_i_port_envelope_r67.py`
- `blender/collection/build_i_port_envelope_r67.py`

45164 是约束点数，不是美术质量评分。原构造的两个壳面层次差使局部需改形，不能声称外表面完全不变。除第一内衬外，其它源网格坐标/三角、法线、UV、形变、变换与材质字段由构建器对照保护。

## 候选与验证范围

1. R67 / `59dd2b7d`：自身闭合、无非邻接三角面自接触；第一件对01/02壳的45个轴向位置检查无交叉。`release_probe/probe.json` 也已完成 R65 分层支柱/穿口检查，当前采样无接触。首次诊断误把本应随内衬一起移动的密封圈固定，失败证据保留 `diagnostic_seal_held_fixed_invalid.json`；修正为圈与衬一起退出、装配位置查相对配合，不能把固定圈穿透解释成有效机构。
2. `smooth_r2` / `9971e402`：将直管尖端高度混入裙边平滑，最大抬高 .06597，形体扩张过大，不采用，也没有完整组装路径验证。
3. `smooth_r3` / `1ae4af00`：只平滑可见裙边，并在原长管外壁增加独立接合环；不再从长管尖端斜接裙边形成尖翼。源与组件已保存，局部自体/皮壳/相对密封检查通过。新的 R65 分层检查所有当前采样无接触，独立 R36 的12片导入膜片/形变与响应对照通过；见 `smooth_r3/checkpoint.json`。这是本版重跑，不沿用上一版结论。

R67c 仍保留两层皮壳对应的高低裙边，最大局部轴向变化 .04573。平滑显著减少近景碎尖高光，但接缝附近仍有折线/薄边，不能称完整工艺或 AAA。下一步需按真实两个承接层处理过渡和裙边厚度，不应继续无界全局平滑。
