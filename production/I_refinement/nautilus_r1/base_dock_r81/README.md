# 底座金属连接候选 R81

本轮承接 R78 的连接纠偏，当前独立实体为 `blender/collection/I_base_dock_r81.blend`，SHA256 `6e365b7932d94754a2d0b7f31abc242800defb608bd31735900aedffec8087be`；组件 `app/assets/collection/components/I_base_dock_r81.glb`，SHA256 `16fc9b825dd173df46f4a74dfc275cda43aa4b7811840f5f1585bc6debb5bfee`。主 App 仍为 R68，本轮没有改 registry 或导出新 EXE。

## 实际改变

移除 R1 的矮圆台和四组直接托瓷壳的造型承托块，改成有定位销与四个锁固位置的安装板、两组短肋板支座、低横梁及金属固定颈。支座落在实际声学金属框 09/10 的下表面，通过六枚从下方安装的短螺钉固定；既有框架至内喉的夹座保留。瓷壳 02 增加两处真实让位孔和随壳移动的镍边，右侧旧包边做相应圆弧缺口，保留其余约 98.3% 体积。不能把瓷壳画成唯一承力件。

共享底座外形、层数、按钮和机身位置未改。独立候选使用 `I_base_dock_pedestal_r80.glb`：只在原安装平面增加六个盲孔，保留外包围范围及原有 32 条几何边界的精确签名；不能称旧合并底座全体闭合。该候选底座尚未替换主程序的共享底座。

新图 `../base_connection_r78/docking_connection_study_r1.png` 采用的是短肋板、固定法兰和金属承力的方向；生成图内虚构的整体骨架未直接照抄。本轮实际支座仍是结构候选：肋板轮廓、接缝/倒角、材质及整机旧壳面仍需继续精修，不是图稿级最终材质或 AAA 验收。

## 失败版本和检查范围

- R79 接到连续内喉的长柱穿过声学膜片，且外观像喇叭脚，拒绝采用，源和失败报告留本机。
- R80 改接金属框，膜片和普通开合干涉清除，但右孔沿碰旧包边，新增支座还有 6 对布尔精度自接触，未通过。R81 对包边开真实缺口，并只合并新增支座上已有连接关系、长度小于 `2e-8` 的退化边；最大世界坐标位移 `1.071e-8`，没有按空间距离全局焊接。
- R81 `contact_check.json`：新件相互及对保留部件的 9 个普通开合姿态无未解释接触；十二膜片在 -1/-0.5/0/0.5/1 五种实际求值形变下不碰新件，且明确测到了形变。原 09/10 框分别 3/333 对自接触的三角坐标与 R76 完全一致，仅作为旧问题保留，不能把它们说成已经修复。
- 安装板/垫层、垫层/法兰是预期水平接合面：整体 Z 极值证明重叠分别为 0 和 `2.384e-7` 场景单位，单独记录，未任意豁免零件碰撞。新件自接触清除；其余网格、法线、UV、材质槽、变换与膜片形变字段逐项保护。
- R81 实际渲染在 `review/I_refinement/nautilus_r1/base_dock_r81/views/`；`baseline/` 为同相机 R76。第 05 张明确是隐藏陶瓷的诊断剖视，不是运行或拆解状态。

## 正常开合动画

独立可编辑动画源 `blender/collection/I_base_dock_opening_r81.blend`，SHA256 `e0c6d12c993a91abf7ad37e287a7d93d967ac41575718bc8e1f76719e10a8e64`。420 帧/30fps/14 秒：闭合停留、4 秒开启、停留、4 秒收回。此文件是预览动画源，不能覆盖实体源。

实际 Godot 影片 `review/I_refinement/nautilus_r1/base_dock_r81/motion/dock_opening_r81.mp4`。39 个新固定件全程保持安装变换；从保存后的 Blender 动画独立读取 1740 个标志点，与 Godot 实际驱动比较最大误差约 `3.97e-7`，源首尾精确回位。视频帧数、时长和首尾图像校验另见 `motion/validation.json`。这是离线正常速度开合演示，不是原生帧率测试，也没有演出新支座解锁。

Godot 独立候选关闭自动 LOD、阴影代理和网格压缩；R76 对照也关闭这些选项重新出图。旧 `r81_views.log`、`r81_motion_qa.log` 是已修正的脚本解析失败，有效日志为 `r81_views_r2.log` 和 `r81_motion_qa_r2.log`。

## 接续顺序

先精修这套已能安装的可见支座，再验证真实工具访问、盲孔螺纹/止退、定位和四枚安装锁的退出；随后重新设计有承托的普通态→检修态转换。R76 原 `.45` 整机抬升/退脚准备态不能直接套用到 R81。R77 的 02 壳直线退出失败结论仍保留。

完整拆解组合、旧框架/壳面缺陷、材料光效、全曲音乐及原生性能和后续型号队列继续 active。没有等待新增审批，也没有宣称这些已完成。

可复现入口：`build_i_base_dock_r80.py` 从 R76 建 R80（读取 R79 的小尺寸调查 JSON，不依赖失败 R79 模型）；`refine_i_base_dock_r81.py` 做局部修正；`check_i_base_dock_r81.py` 独立检查。跨机精简交接只带最新 R81 实体/动画及必要报告、候选底座，R79/R80 历史实体不打包；若要重跑 R81 构建，先按脚本重建 R80。
