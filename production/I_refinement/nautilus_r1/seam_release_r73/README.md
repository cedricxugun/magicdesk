# R73 分离式夹环螺纹候选，未接App

源 `I_nautilus_seam_release_r73.blend` **86b25cf7** /组件 **3740d10a**，从R68构建。仅两根SeamCrossBolt改为真实分离销/盲孔螺帽，+1整对反向以便从上方拆帽；保留1233其它网格字段。App仍R68。

旧R64名义径向间隙 .00025 大于牙纹 .0002 起伏，不能靠其“有螺纹纹路”证明咬合。当前局部间隙 .00004、径向咬合 .00016、节距 .001；销与螺帽退刀段采用相同轴向节点，修复独立网格跨退刀段产生的318对闭合接触。旧失败诊断保留。

有效 `thread_interlock.json`：两对初始配合无接触，分别101个实际螺旋位置无接触；只沿轴硬退1/4节距或只转1/4周会发生相交，证实本候选有几何咬合。不是强度/扭矩/整机动作验收。

必须使用IC1_MouthMount局部节距与实际安装缩放 .7，绕Y的theta=atan2(z,x)与右手正转方向相反。正确旋出是在局部行程dy下 angle=-2πdy/pitch，再将轴向位移乘安装基向量。第一全组probe把符号和世界/局部单位用错，不能用其phase0或thread_interlock结论；独立初版world_units_invalid也保留。最终有效记录是thread-r2日志和本目录thread_interlock.json。

夹环就地抬开路线仍未解决。R74另以可靠R68检查“口部+闭合夹环”整体前移，几何可行，但连接螺栓的真实短咬合尚需制作。不要根据R73局部螺纹通过推广整机源或更改R71旧动画源断言。
