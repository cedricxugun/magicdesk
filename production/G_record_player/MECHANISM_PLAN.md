# 六瓣换片机 · 机构设计草案

这是新形态与运动方案，尚未建成模型。旧书本方案已暂停；六件藏品可以复用，但精修要求继续有效。

六片烟黑档案盘存放在后侧的六槽旋转盘匣中。每片有金色包边与独立卡槽，盘匣先将所选唱片旋转到唯一的前侧取片口。机械爪只走“固定取片口—前方唱盘”的路线，减小自由度和穿插风险。

| 阶段 | 可见动作 | 必须满足的条件 |
| --- | --- | --- |
| 选片 | 编号亮起，盘匣转到档位并锁定 | 夹爪为空，唱臂停在外侧 |
| 取片 | 三指夹爪抓住边框，垂直提起原唱片 | 先夹稳，再离槽；该槽保持可见空缺 |
| 转运 | 唱片提到邻片上方，再翻腕放平 | 翻转不能穿过盘匣或相邻唱片 |
| 落盘 | 唱片落在前方唱盘，夹爪松开并退回 | 同轴，无重复生成 |
| 读取 | 唱臂落下，扫描点沿盘纹移动 | 夹爪离开后唱盘才开始转动 |
| 打印 | 唱臂让开，藏品从原唱片表面向上逐层构建 | 唱片始终留在唱盘；爪和唱臂已让出空间 |
| 互动 | 唱片和藏品共用同一旋转轴，缓慢同步转动 | 默认 60 秒一圈；操作藏品时停转，停转按钮始终可见 |
| 归片 | 藏品反向打印回收，唱盘停稳，原片送回原空槽 | 先回收模型，再移动唱片，不生成替身；在安全转运区由腕部恢复盘的入槽方向 |
| 休眠 | 唱臂、夹爪、盘匣归位并熄灯 | 六片全部在槽，无悬空零件 |

视觉：原子之心式仿生机械，花萼形陶瓷卡槽、骨节状金色关节、烟黑盘面和暗红指示。避免大方柜、木质留声机和没有功能的巨大喇叭。

尺寸：共享底座外径 2.74、高度 0.670608，保持原模型。唱片直径 0.50，六槽盘匣半径 0.52，读取小唱盘直径 0.80。小唱盘是底座前半部的独立模块，不能把整个底座上表面当作唱盘。肩部两连杆长 0.62 / 0.68，配腕部翻转和夹爪；仍需三维实体碰撞检查，解析可达性不替代网格验收。

`images/G_record_flow_draft.png` 仅为形态/叙事草图：其中落盘后的唱片被放大，部分槽位/编号也不一致，不能作为几何基准。正在另出恒定尺寸的双状态校正图。

用户最新决定：采用类似现有“切换模型”演出的打印显现。应复用其扫描边界/逐层构建语言，不能先撤走唱片再显示藏品。打印模型、黑色盘和小唱盘是同一旋转层级；底座、盘匣、机械爪不跟随展示转动。60 秒/圈等于 6°/秒（0.10472 rad/s），不是常规黑胶唱机的高转速。打印和回收期间需处理好转动坐标，避免扫描层错位或残影漂移。

侧视坐标（y 向后，z 向上）：肩点 (0.38, 1.58)，唱盘中心 (-0.72, 0.905)，取片中心 (-0.08, 1.18)，盘在匣中倾斜 60°。先竖直提起约 0.33，再翻腕放平和转运。采用肘部向上的解绕开盘匣。这里只是布局初值，生成图也不视为通过碰撞验收的结构图。
