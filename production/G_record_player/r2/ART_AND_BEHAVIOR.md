## 一件机器，两套可独立运动的末端

AI 面部俯仰/偏航与吸附器定向分离。表情动作只转动眼部外壳/颈部，吸附器保持指向唱片法线，因此歪头不应使唱片歪斜或掉落。吸附是科幻场力设定；如果加入弹性滞后，需明确为有重力补偿的受控运动，不能把预设漂浮轨迹称为真实磁悬浮仿真。

吸附链：看向选中编号 → 盘匣定位 → 投射器对准 → 短距离结构光形成 → 原片离槽 → 抬到邻片之上 → 转为水平 → 转运 → 同轴落盘 → 吸附场收回 → 唱臂读取。持片时期该槽一直空缺。光束止于不透明唱片表面，不能穿透盘片在下面地面形成第二光点。

后续保持原片 ID 与所有权唯一。换片/关闭在任何阶段都按安全逆序处理，不突然熄掉承载中的吸附场；先落稳或归槽，才能结束场力。需按新半径和机头体积重新算可达性、避障、场线遮挡与拆解路线。

## 表演与状态

| 状态 | 机头 / 快门 | 像素表情 | 场和物件 |
| --- | --- | --- | --- |
| 待机 | 小范围目光游移，8–14秒一次短眨眼，偶尔约8度歪头 | 安静注视；偶尔一侧眼睛眯起 | 吸附场关闭，盘片各自在槽；不擅自启动 |
| 选片 | 先转向对应编号，再开始机构运动 | 目光明确偏向选中片 | 编号接点短亮，盘匣完成定位 |
| 吸片 | 快门略收、俯身确认 | 集中目光 | 短场线由弱到稳，锁定原片；运动有轻微收敛阻尼 |
| 读取 | 视线跟随唱臂接点 | 专注窄眼 | 盘纹局部唤醒，接触点可见；与后续打印阶段区分 |
| 打印 | 退到构建体积外，目光跟随成形高度 | 细小的工作节拍，避免高频闪烁 | 结构线抽出、金属形成、釉面封合，密度与声音在接合时达到峰值 |
| 完成 | 短暂停顿，再向用户侧头约8度、眨一次 | 得意眯眼 | 构建粒子和骨架退净；钟摆/齿轮启动，原片和藏品共同60秒一圈 |
| 取消 / 换片 | 先确认指令，再关注回收位置 | 简短眨眼确认 | 从当前进度反向回收，保留物件和场力连续性 |
| 休眠 | 原片归槽后小幅低头，快门真正合上 | 最后一个暗琥珀短线随后熄灭 | 投射器关闭，只有弱待机灯 |

单次眨眼可从合拢 .12s、停留 .06s、打开 .20s 开始调；任何空闲表演在输入/动作时让位。大幅搞怪只在空闲且无唱片被承载时发生。禁止用常驻大幅摇摆让用户难以操作。

## 打印效果的制作分层

1. 盘面：专用干涉纹样贴在实际唱片表面，中心与转轴一致，颜色随设备光源设定统一变化。
2. 抽丝：带真实三维深度和遮挡的细曲线，从盘面扇区送往模型实际结构锚点；图集只调制光强，不用整张贴片假装立体。
3. 档案骨架：从最终模型的结构抽取真实三维线框/细杆，不使用通用圆柱体全息罩。
4. 实体形成：沿唱盘局部高度，金属框架先成形，瓷面随后封合；窄白金形成边与局部光照结合，精确落在构件表面。
5. 微粒：沿锚点方向收束进接缝，进度峰值时增加密度和短拖尾；不随机飞满桌面，不保留完成后无意义的星星。
6. 恢复：骨架、细丝、粒子完整消退，实体仍可看清正常釉光与金属光泽；默认不靠过曝撑观感。

先分别做吸附/建筑打印的中间阶段实机对照，再组合完整连续动画。需检查原尺寸窗口中的观感、移动中的透明遮挡、首次播放预热与帧时间；通过状态机测试仍不能写成达到 AAA。
