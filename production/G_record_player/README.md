# 六瓣换片机 · 同盘打印

用户最新方向：取消方形书壳，围绕能实际取放的黑色档案唱片，制作原子之心风格的仿生自动换片机。

**首轮唱机已制作功能试制并完成实体控件回放，但用户明确拒绝其比例、模型和特效质量。当前采用球形快门 AI + 光束吸片的新方向，详见 [第二轮图稿、行为与素材](r2/ART_AND_BEHAVIOR.md)。新AI造型与特效尚未接入模型/EXE。** 下方旧爪式图与尺寸仅作为历史，不能优先于 r2；旧书方案亦保留但不作为新版本交付。

2026-09-10 已补 [独立特效分镜与素材](r3_fx/README.md)：吸附、解码、构建、回收四组三阶段图，及独立光束/盘纹纹理。换机时先看仓库根目录 HANDOFF 顶部。

取片后，原唱片一直留在前方小唱盘上。唱臂读取并让开，档案物件从盘面逐层打印，然后与唱片共同缓慢旋转。默认 60 秒一圈，操作时停转，有明确的停转入口。换片先反向回收物件，再把原片送回原来的空槽。
