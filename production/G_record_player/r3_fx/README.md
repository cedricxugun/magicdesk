两张都是黑底单色强度遮罩，黑色表示不发光。它们不含透明通道，也不是可直接贴成一整块的最终特效。颜色由运行时统一控制：默认暖金供能、冷蓝档案骨架、白金接合峰值；换色时纹理、微粒、接点和局部灯一起响应，不能只改其中一层。

上一轮 `G_AI/optical_field_atlas.png` 的微光点与枝状强度素材继续保留，可辅助微粒和构建丝。新独立纹理提供更充足的采样范围，避免在四格图集的小区域内拉伸。

## 动画与强度契约

以下是制作起点，不是已完成的动画参数：

| 段落 | 节奏起点 | 严格门槛 |
| --- | --- | --- |
| 光场锁定 | 约 .25–.35s；先接点再光丝、最后薄体积 | 投射器已对准原片，光束不得穿过不透明唱片 |
| 光场承载 | 随实际转运持续，不独立循环开关 | 只要片还在悬空承载状态，场力就保持；表情机头动作不能带偏投射器 |
| 落盘释能 | 约 .20s；盘面接点先退、光丝向上收 | 片已落稳才释放，吸附消失前不能继续下一段 |
| 盘纹解码 | 约 .9–1.2s；编码光轨顺纹路递进 | 唱臂位于真实读取位置；曲线局部坐标随唱片转动 |
| 打印交接 | 约 .16–.24s，收束到中心种子 | 唱臂和AI已经退出构建空间，才允许建筑几何出现 |
| 构建 | 约2.7s；进度0–.35拉出结构，.35–.70实体形成，.70–.86接合高潮 | 下部实体、上部实际结构骨架；不能把完整物件从小缩大代替构建 |
| 封合与启动 | 最后约 .3s；微粒/供能线减弱，机械启动 | 最强光与最多微粒发生在接合高潮，不能临近峰值反而变弱；最终骨架与光丝清零 |
| 反向回收 | 完整回收约1.3–1.6s；取消时从当前进度反向 | 上部消失、下部保留原尺寸；最后所有构建效果清零，才开始拾取原片 |

强度随动作进度控制，不用独立计时器反复开关。待机保留眼睛/快门性格和少量实用灯，吸附场、盘面读取、打印粒子全部为零。中途选片、停转、取消、拆装、关闭都必须从当前状态连续转接。

## 三维实现要求

- 光束：短三维场体、真实光丝曲线和盘面接点分层；纹理只调制光强，不能用平面三角贴图冒充体积。实体唱片负责遮挡；接点附近应照亮瓷/金属，不能穿透到底座下方。
- 盘纹：叠在唱片表面的局部光轨，采用真实转轴坐标和扇区遮罩。只显示当前解码的少数轨段；不能整张纹理同时亮成普通发光圆盘。
- 构建骨架：从最终观测塔的真实结构抽取三维线和节点，使用正确深度；不得用通用空心圆柱、方形全息贴片代替。
- 构建细丝：从六个盘面扇区到实际接缝/关节，沿三维路径输送微粒。图中的接合轨迹是贴近结构的短轨迹，不能扩大成离体法阵。
- 形成边：随实际构件高度推进、与材质封合一致；粗糙度/颜色/局部反光联合变化。完成后正常瓷釉和金属反射要独立成立。
- 完成/回收终点：所有临时网格、微粒、体积、灯和声音都按状态归零，不能靠把整个节点突然隐藏来掩盖错误节奏。
- 桌面透明合成：不得留下黑底矩形；只把强度转换为光/透明度。最终要检查光的透明边缘、深度排序、遮挡和首次预热，四组分镜并不代表这些检查已经通过。
