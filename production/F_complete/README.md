# F · 拉格朗日天平

这轮只推进 F。目标是让“看见受力、驯服惯性、完成校准”成为装置自己的玩法与演出。

## 操作

悬停预载旋轮后滚动鼠标，或左右拖动。Shift＋滚轮可微调。制动夹持续按住时刹住连杆，两只配重仍有余摆；松开后释放。磁偏置可上下拖动或用滚轮切换三个档位。让合衡表指针靠近左侧并稳定，装置自动完成一次校准。

说明需停留 450 ms 才显示，位置在整排控件上方；按下、拖动、滚动时隐藏。状态通知与说明不会叠放。控件侧视的命中范围增加了有限容差，旋钮不再要求画圆。

## 完整表现

1. 收纳：配重夹爪保持，接收盘在弧形壳前方。
2. 释能：接收盘先升起再滑入，夹爪释放，悬挂受重力启动，内沿导体亮起。
3. 失衡：磁针与细小金属屑沿随配重变化的场线流动。
4. 制动：主轴停住而两只配重各自余摆；局部制动指示随耗散出现。
5. 合衡：稳定后，28 枚实体金属针排列成两层悬浮刻度；铅垂光线接到测量盘，盘面出现干涉波，金属得到局部暖光，播放专用校准声。
6. 回写：刻度散开回收，一枚光点沿弧形标尺回到游标；待机只保留很弱的参考光。
7. 组装/收势：先平息场和悬挂，夹爪收住，再沿反向收回接收盘和连杆；支持过程中反向操作。
8. 拆解与关闭：18 组结构拆出并回到原位；关闭有收势、熄灯与退出。

## 制作链

`complete_f.py` 从保留的 F_refined 源建立新结构 → Godot 的 `f_visual_take.gd --bake-only` 记录同一物理与控制数据 → `bake_f_take.py` 烘焙回 Blender → `verify_f_clearance.py` 检查实际网格 → 导出 Windows EXE 并经原生输入回放。

动力学定义及验证边界见 [PHYSICS.md](PHYSICS.md)。其余装置没有在这一轮开展上部模型精修。
