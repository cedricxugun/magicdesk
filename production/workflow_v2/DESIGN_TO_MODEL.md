# 从效果图到模型：制作流程 V2

2026-09-12，回应用户要求改进首轮准确性。该流程取代“自由出图后直接高细节建模”的默认做法；用户已授权的队列继续自主推进，不新增逐阶段确认。

## 原因与原则

概念图确定造型与气质，但其中的透视、结构、不同视角和生成数字可能不一致。把数字直接写进生图提示词，不能使图片成为可测量CAD图。之前I的形体未锁定，就制作大量内部件和音乐投射，导致技术工作累积在错误主体上。这是制作顺序错误。

**几何与尺寸的唯一真值应是可测量的3D源和契约；图中的数字由实际几何计算后标注。** 概念图仍是艺术目标，不能反过来用自己的错误模型和派生图解释目标。基模没有通过形体对照之前，不得把它设为已锁定设计。

## 1. 将原图拆成可检查的造型要求

记录识别特征和禁止漂移项，而非只列零件数量。I的要求是饱满弯卷的海螺、口部嵌入侧前方、口后/口下有完整体量、顶端回卷、展开后仍保持海螺身份；“尖锥弯管+大圆盘”不满足这些要求，即使尺寸和动画接口正确。

来源优先级：用户最新明确方向 → 用户原选图及动作说明 → 正确形体的三维契约 → 后续部位细化图。辅助生图必须指出哪里与原图不一致；多角度生成图不能直接称正交图。

## 2. 首轮先做形体，固定相机检查

使用真实共享底座，建立最少足以识别形体的主体、口部、主要支承和活动分片；先不堆螺丝、管线、复杂特效。

输出固定分辨率、固定投影和固定取景范围的正面/侧面/背面/顶面，另保留一组与原选图对应的展示透视角。所有候选都使用同一套相机，禁止自动缩放来遮掩体量改变。

检查至少包括：整体剪影、最大体量位置、主体弯卷方向、口部位置与朝向、口部和主体的大小关系、负空间、主要连接。显著偏离时回到形体阶段。当前没有可校准相机或可靠正交参照时，不能编一个“还原度分数”。

## 3. 形体正确后锁定尺寸契约

契约记录坐标轴、真实底座D、安装平面、主体长宽高、口径/厚度、关键点坐标、口部法线/倾角、支承接点、活动件枢轴、允许运动包络与版本哈希。尺寸可同时提供场景单位和D归一化比例；未经真实尺寸定义不能标成毫米。

先保留当前实测值与目标值两列，不混为一谈。契约未锁定时输出必须写“候选/未定型”。形体锁定是有图像证据的内部制作判断，不是伪造用户验收。

本轮拟定的下游偏差起点：关键点漂移0.005D、轮廓边界漂移0.01D、口部轴向漂移2度；仅在正确形体锁定之后使用，按实际视觉敏感度调整。共享底座本身仍保持精确不变。这些不是原图提供的数值，也不表示当前候选合格。

## 4. 以几何受控的底图细化艺术

从锁定三维源生成固定相机的灰模、剪影，以及需要时的深度/法线/部件遮罩，作为内置生图的参考。提示词明确只细化指定材质/部件，不改主体、底座或枢轴。

参考输入并不能保证生图绝对不漂移；产出仍需与三维轮廓和契约对照。发生漂移的图不能自动变成新目标。缺细节时按部位补图，不靠反复整机重画改变形体。

## 5. 分件、动作和实时画面分开验证

离线脚本手动改变自定义属性时，必须显式刷新相关驱动对象，并断言求值后的真实变换/形变权重达到请求值。仅记录设置过的属性值，不证明依赖图已更新。I 膜片手动幅值检查曾因此漏检头肩与固定轴颈的接触；修正与独立GLB几何对照见 `production/I_refinement/part_a_mouth/shutter_r2/cassette/diaphragm/COMBINED_RESPONSE.md`。属性驱动采样与时间线动画采样应保留各自的范围。

对动画纹理/行数据驱动的薄片等变形网格，源顶点和数据哈希吻合还不够。必须核对实际渲染所用的索引、LOD、阴影/深度网格及属性精度，在曲率最大的运动帧做同相机着色对照。基于 REST 生成的简化网格可能在卷曲时产生破面感；需要保留完整拓扑，或另行验证覆盖全动作的 LOD。I 首片反馈的定位证据见 production/I_refinement/part_a_mouth/shutter_r2/cassette/RASTER_FIX.md。此项是内部制作校验，不新增用户审批。

分件记录唯一ID、父级、枢轴、连接/配合面、厚度、止挡、机构行程及装回位置。首轮在同一模型/相机上做闭合、起势、25/50/75%展开、完成和恢复关键帧，然后连续扫掠、反向/取消检查。

动态着色还要做“源材质同姿态”对照：只保留位置/拓扑仍可能丢掉源的边缘法线、高光和拉丝方向。I 薄片曾在变形时用整张曲面的解析法线覆盖原始边缘法线，导致边缘显得发平；仅把切线方向正交化也不足以恢复工艺。现以额外静止参考坐标架传递原有法线/切线，REST直接与同一网格的StandardMaterial渲染对比，运动中再核对曲率和边缘。参见 `review/I_refinement/part_a_mouth/shutter_r2/foil_frame/`。新增自定义顶点属性时必须验证实际网格仍存在、位置/索引/UV保留，并以原有ArrayMesh重建作对照区分固有的法线编码误差；不能让空网格仍通过只检查控制时序的测试。

曲面贴合件要检查整张面，不能只检查采样顶点。I卡扣垫片的均匀网格顶点虽投到瓷面，三角面仍局部穿过曲面；改为裁切打孔后实际瓷壳三角面、排除盲孔底面，再生成厚度，消除了该采样插值误差。原有内衬、后方承座也必须一并检查，不能只确认卡扣贴在外壳上。案例在 `production/I_refinement/part_a_mouth/shutter_r2/cassette/collar_clamps/README.md`。

运行ACTIVE与检修ASSEMBLY不能混用作对照。状态不同的图不能用来证明同一状态还原。全组模型源与运行时姿态对照、关节接点和局部碰撞只证明对应技术范围，不自动放行整体美术。

最终在真实App尺寸下检查材质、光影、特效、可读性与操控。保留中性几何视图与美术画面两套证据；不得用灯光/特效遮盖结构和轮廓问题。所有最终动效仍按PRODUCTION_ART.md先有设计和专属视觉资产。

## 已落地与接下来补齐

2026-09-14 包边预检补充：表面带裁切应按原顶点和原边身份复用交点。R17排查了按距离焊接误合并近壁面的风险；`i_indexed_surface_band.py` 改为拓扑交点缓存，近邻双层面的独立连通性已用合成反例检查。09面带的实际非流形随后定位到源的渲染三角化：原多边形边连通检查没问题，实际三角索引却包含两对反向重面。拓扑检查必须同时覆盖最终渲染三角面，R16b已有独立修复和坐标/绕序/材质槽对照证据。整批预检需保留全部失败角点、源面带和定位场景，以便设计分段构造。

倒角记录需包含实际几何变化与生成面质量。R17曾选中多条边，但全局重叠夹紧使宽度接近零，留下大量亚精度面；这不等于圆角完成。无实际效果的倒角试验保留并退出当前候选，几何圆角仍列为未完成。成型包边的接触、轮廓、材质与未覆盖段分别核对，局部可用段不代表整圈完成。

2026-09-14 补充：对非平面四边面，顶点相同仍可能因重分割对角线改变真实曲面。先把原始实际三角面固定，再做壁厚、布尔、导出和检查。生成内外两侧时，用源顶点编号和整层连通关系追踪来源，不能逐点挑最近副本；内外标签须写到所有新顶点。保留原外侧角点法线，避免几何不动却改变了着色。

检查实体间距要覆盖面与边，不仅是顶点。最近点投影会在凹处留下穿过表面的长边；R4接收槽试验已出现此问题。真实三角面上的相交及点面/边边距离，才是对应网格的证据；它仍不证明完整动作、载荷、导入LOD或艺术效果。极细三角面也会使浮点最近距离不稳定，外表面不变应优先证明原始三角面的有向对应及原坐标，而非只比较最近距离。

记录失败试验和可接续候选。名义壁厚、工具选项或一份绿色报告不能覆盖其他失败项。当前I已检查接续为 `production/I_refinement/nautilus_r1/throat_terminations_r16/README.md`；R13已补到十一组夹座，R16清除九组旧框膜对后法兰/内衬相交，R17包边仍在制作。薄区、04、膜片边缘、底部支承和全模型仍待收尾，整体不因局部检查通过而完成。

夹持件要分别检查框架正面、背面、膜片前后及内衬内外层。背面足印完整，不代表正面压盖也能贴合。喉口侧薄内衬按实际壁厚选贯穿螺钉/内侧背板，不能只放宽盲孔深度阈值。加工后对分离的既有前后片段，逐一将孔缘采样归属到真实连通组件，证明每块各有安装座，不能用零件总数代替。R12记录了完全同顶点、反向法线的零体积布尔薄翅；只去除该确证重复面，保留有实际体量的片段。

## 2026-09-15 可见问题先做实际渲染归属

修改一个“看上去有问题的部位”前，先在当前源、实际相机与同一动作状态下做无光照的逐对象着色，记录明确的坏边像素归属；必要时再查三角/法线。大片区域射线命中不能代替细条、相邻覆盖件或投影处的归属。R44大面命中01，R48实际着色才确认前下条纹主要来自06；R45/47的01返工因此未采用。

分别对照主/局部阴影、SSAO、材料高光，保留关闭效果的图作诊断，不作为交付。扩大重建范围前采样截面的连接数量：R46显示01从一环变两环，不能把两个深截面分别拉回同一前口。只有同状态实图显示目标改善，且接口/动作保持，才接续新源；检查通过数不能替代视觉收益。沿用用户既有授权，不新增逐阶段确认。


## R63 拆解与动画源对照补充

- 先定义真实准备姿态和模块归属，再寻找退出方向；不能把活塞/密封件随前罩硬拉穿筒体，也不能仅凭图中的浮动间距判断机构可拆。
- 碰撞诊断保留实际三角所属零件名；先退真实止退件/销轴，再沿叉口方向退出，最后移向便于观看的位置。机械路径通过后仍须看实际画面，避免模型虽分离但在投影上挤在一起。
- 独立Blender目标标志点校验真正导入的动画与实际模型。对于精密装配动作，要检查导入器是否删去等待关键帧；保留等待时间和原轨迹，不能靠扩大误差容限刷绿。
- 局部回装至准备态、普通工作开合、完整合壳是不同状态。检修驱动绑定前验证准备姿态，退出后逐标量核对复位，并把全局展示旋转纳入坐标检查。
