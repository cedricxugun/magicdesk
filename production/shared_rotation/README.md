# 共用全息旋转入口 · 已接入开发版，原生鼠标待解锁复核

用户提出把通用模型旋转从实体按键移出，改为底座右侧隐蔽发射口投出的悬浮全息按钮。

`concept_v2.png` 是当前方向图：保留真实底座外径/高度与前面操作匣；右侧低位环缝中的狭小发射口，接近后显影的小型环形控件。运行时外环转动、中心显示暂停操作；暂停时环停驻、中心给出旋转操作。点击压缩、单次回波、回弹，随后淡回低亮。浅冷青色全息层与现有奶白/镍铬/克制暖色硬件搭配。

`concept_v1.png` 不采用：新入口离红色关闭键过近，且误将场景尺寸标为英寸。v2已改为轮廓外的按钮和低位环缝，但实际几何、投射位置和点击区仍须以原底座网格与真实相机校准，图不是尺寸证据。

实现时：
- 不改底座D2.74/H0.670608，不增高、不新增独立底座。
- 共享按钮控制整个模型的展示旋转；G现有toggle_rotation特殊分支实际控制唱盘慢转，必须拆清语义。唱盘、海浪等专用机构不能误删。
- 保留空格/右键菜单作为可发现的备用入口；物理操作匣释放通用旋转位置后按每款需要处理。
- 实测悬浮控件与红色关闭键及机械牌架的屏幕命中区域，任何缩放档都不能重叠。
- 悬浮入口要使用设计后的专属图形与反馈素材，并按真实发射口位置合成，不以普通二维悬浮黑色面板代替。

已按v2制作专属SVG和贴合低位环沿的独立发射窗GLB，并接入 `rotation_hologram.gd`。底座尺寸未改；淡出时保留低亮环迹，接近显影，按压缩小15%，释放回波、回弹；展示旋转中外环缓转，中心给出暂停动作。投射线止于环沿，不跨过中心图标。发射口有局部冷光，真实照亮旁边金属。空格/右键菜单统一展示旋转，G实体唱片慢转功能保持独立。

共享输入测试验证了按下捕获、一次释放一次切换、切模型时隐藏、B/G共用、70/100/110%点击区避开关闭键及不出画布。见 `review/shared_rotation/headless_qa.json`、`gpu_qa.json` 和对应截图。最后细线端点/扫描纹理调整已打入日常Mac包。**CUA随后发现Mac锁屏，所以最终原生鼠标穿透、点击和白桌面可读性尚未验证。** 已提示用户解锁，其他制作转F继续。不要把原生签名和输入脚本算作原生鼠标验证。

日常包构建记录 `review/shared_rotation/native/build.json`。旧概念图与目前几何/参数仍保留，可继续调光效；不声称AAA已验收。
