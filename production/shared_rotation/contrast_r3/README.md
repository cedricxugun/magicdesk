# R62 共用全息旋转入口可见性与取消修正

沿用 shared_rotation/concept_v2.png 的隐藏发射口、分段圆环、旋转/暂停、按压收缩和回波设计；本轮是现有矢量资产与合成参数精修，不新增外部图片API或替换模型。I结构仍为R61/0ba13905，所有其他模型目标保留，无新安装包。

## 修正

待机amount=.28原先再次乘.70，只剩.196透明度；中心图标还把同一数值当显影进度，只有少量区域可见。现在把待机亮度与完整显影分开，待机face_gain=.68、face_reveal=1，接近后增强到.94。隐藏/切模型仍淡出到0。

新专属SVG在 app/assets/collection/art/shared_rotation/contrast_r3/：保留原圆环/旋转/暂停形状，用深青边与浅青亮芯适应浅深背景。没有黑色圆盘、矩形底板或扩大底座。原SVG保留；投射线和回波仍沿用既有资产。按住压缩、释放一次切换并发出一圈回波；回波稍增强，取消不触发。

ICON_POS(1.91,.28,.27)、PORT_POS(1.34269,.145,.27218)、ICON_SIZE .28与发射窗GLB都未改变，点击半径也未增大。

新增取消入口：窗口失焦、桌面缩放及打开牌架会清除悬浮按钮的未完成按压。available同时检查selector_target和selector_wait，消除“点击开牌架后、首帧动画前仍可点击”的空隙。按下后移出释放不切换，重复释放也不重复切换。

G原专用慢转菜单/快捷键路径仍强制host.rotation_enabled=false；现去掉该联动。共同展示旋转与G唱片慢转双向独立，保留所有原唱片机制，不把它们删除或合并。

## 证据

- render/：实际原底座+真实旋转控件的轻量渲染场景，白/灰/深背景、待机旋转/暂停、接近、按压与释放对比已看。该场景的简化host只用于外观与控件行为，不能冒充完整主App。
- render/contrast_measurement.json：同一位置和点击区的像素对比。深/灰底旧待机几乎不可见，新图标有清楚轮廓；数字不等于可用性或AAA认证。
- main_r2：实际main.tscn、B/I/G、焦点取消、牌架即时禁用、I音乐继续、G两种旋转互不干扰、返回B和一份共用入口/底座检查通过，日志无脚本/资源错误。70/100/110%是实际执行Mac投影分支且FOV有三个不同值的检查；它使用工作渲染器相机，不是逐档原生鼠标验证。
- 首轮main结果不采作全通过：找到真实selector-start命中空隙，同时缩放函数在render-probe模式早退，旧“多档”标签无证明力。main/NOT_ACCEPTED.md保留原因，main_r2修复。
- native/：CUA实际点击新主App中的左拨钮开始月光，再点击全息入口开启/停止展示旋转，两次状态读取均仍playing；待机完整图标与浅色背景已截图查看。随后通过真实菜单“重置视角与位置”复位到正面，当前播放继续。G独立性是主场景合成事件检查，并未声称本輪完成G原生点击。

## 保留范围

这是共用入口的一轮修正，不是完整特效或所有装置验收。连续演出与多桌面背景/长期性能仍可继续调优。I前罩侧边回折/内衬、完整拆解、内部工艺/动力、全曲逐音校准、首次加载与切换性能，以及F/I/J/K/L/M/N/最后G队列均active。不得因B/I/G这组检查通过就称全目标完成。
