## 现在的逻辑

`desktop_scale.gd` 按 BASE_FIXED 的 D2.74/H0.670608 契约计算投影宽度，不把可替换舱罩、按钮凹槽算进尺度。默认底座逻辑宽度取屏幕逻辑宽度28%与可用高度39%的较小值，限制在260–400点；本次屏幕配置约338点。用实际 backing scale 转成渲染像素，切换型号不重新计算尺寸。

右键菜单中提供放大、缩小、恢复默认；⌘+、⌘−及⌘滚轮可用。范围70%–110%，调整镜头投影，不改变底座或模型几何。设置保存到原应用 settings.cfg 的 display_zoom。复位视角也会保存默认大小。为完整拆解预留了固定取景余量，禁止每次模型切换随意缩放底座。

透明画布宽度最多2048渲染像素，高度随可用屏幕；保留原生分辨率，并在2×及以上Retina上使用2×MSAA。没有用低分辨率模型贴图放大来替代3D。首次尝试整屏宽画布导致额外开销，已收窄无用左右留白。
