## 本轮工程修正

- Windows 原生窗口启用九款集合，显示实际舱罩入口和实体铭牌。
- 新控件的命中区域发送到原生窗口，拖动控件不会误拖整个底座。
- 新操作匣安装位置取固定基准，修正继承旧操作匣缩回位置、埋入白色底座的问题。
- 切换和关闭释放已按住控件，输入有捕获与释放。
- 拆装拨杆调用真正收拢，M 的组装不再被旧“重构行星”快捷动作占用。
- 原 B、F.blend 和 F.glb 保留；F 精修用兄弟文件，公共底座不重建。

## 验证边界

`tests/collection/gesture_logic.gd` 检查控制因果关系与 F 新机构；
`tests/collection/native_interaction.py` 从 EXE 自身的窗体输入处理，经 TCP 桥和三维射线选择铭牌、控制与组装，捕获真正原生合成帧。它不是人工鼠标录像，也不代表八款已通过美术验收。

最终素材、机构、完整招牌动画和特效按款继续制作。当前版本是可运行的交互评估版。
