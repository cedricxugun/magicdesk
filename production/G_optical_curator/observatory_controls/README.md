# G0 操作反馈与 Mac 检查：2026-09-10

已有观测塔完成一轮实体操作修改，并在独立导出的 Mac App 中实际点击/拖动/滚轮检查。G整体和整批精修仍未完成。

## 修改

- 原有实体瓷牌显示“调时”和“按住共鸣”；滑轨上方显示时间偏移量，未完成读取时显示装载中。字牌跟随真实操作匣，不是浮动面板。
- G0滚轮每格一分钟，Shift每格12秒；拖动全程90个内部坐标像素。原来的参数限速、±30分钟范围、蓄力/回落保持。
- 已有光纹采用不足一个屏幕像素的采样覆盖，保持原素材形状，正常镜头对照从41个到98个指定阈值以上差异像素。本轮没有生成新图，沿用既有专属光纹。
- 其他藏品保留原参数定义与铭文。动态字牌在选中G0时替换原铭文，切到其他藏品时恢复。

实现：`observatory_console.gd`、`record_console.gd`、`control_driver.gd`、`observatory_calibration.gdshader`。动态字牌/读数与GPU光层尚未同步为Blender演出；原机械动作源未修改。

## 输入证据

`observatory_control_take.gd` 通过真实屏幕射线与InputEvent回放，验证控制器中心命中、一分钟滚轮、Shift微调、18个内部像素对应12分钟、实体读数、按住充能和捕获取消后释放。七项通过。这组与原生操作证据分别保存。

独立检查包：[MagicDesk-G-review.app](../../../dist/macos-review/MagicDesk-G-review.app)。本地arm64签名验证通过，旧Mac包保留。这是包含全部开发资源的检查包，不是全批完成版。

使用 CUA 操作导出包的真实Mac窗口：

1. 点击调时滑块，实际取出原片并构建G0。
2. 从屏幕(421,553)拖到(439,553)，Retina映射到36个内部坐标像素，偏移从0到+24分钟。
3. 在同一控件滚动一次，偏移到+25分钟。
4. 实体共鸣压板按下/释放，动作计数从0到1，释放后能量恢复0。
5. Cmd-Q收束退出，进程退出码0。

截图与实际运行状态：[native_controls](../../../review/G_optical_curator/native_controls/)。[原生报告](../../../review/G_optical_curator/native_controls/native_input_report.json)记录包哈希及各项范围。`--control`仅作初始选择G和只读截图，未用于上述鼠标输入；不能把初始选G当作模型选择牌UI验证。原生长按峰值没有单独抓取，充能峰值证据来自InputEvent回放。

## 尚待处理与接续

实际Mac窗口的文字仍偏小。捕获时FPS为42–44；仅四个运行快照，不是完整帧时基准，更不能声称60FPS达标。整G还需要小字/易读性、资源性能、完整构建回收、动态源资产和发布验证。

G0已有这一轮结构、材质、动作及原生输入成果，保留上述问题到整G收尾。下一项是藏品1“瓷翼机械蝶”的设计匹配、翼根结构和动作资产，不重复G0已有检查。AAA和用户视觉验收均未通过。
