## 已修正与检查范围

初版船首偏平、波浪像薄平轨，已改船首/船尾收尖和带厚度渐细的曲波浪。移除贯穿偏心轮的中心支杆，改为绕开波浪通道的固定叉架；增加连续凸轮轴和直线导杆的实际支脚。

帆从桅杆两侧分别引出，独立轴座错层。源动画每帧将帆索两端固定在真实帆角和甲板绞盘处，避免转帆时连接断开。波浪滚轮按实际偏心盘的接触位置升降，运动套筒应保持在导杆行程内。

第一轮92个姿态采样发现前帆转动中与船首穿插，旧报告保留为 `before_jib_clearance.json`。随后提高前帆轴座、缩短帆顶，最新 `source_check.json` 的92个源姿态采样通过：前帆穿船首已消除，帆索端点误差小于6.83e-8、凸轮接触误差小于1.96e-8，导杆行程未越界。检查仅覆盖帆面之间、帆与支索/船壳、帆索端点、凸轮接触和导杆行程；不能扩大为所有硬件、船壳内部及唱机避让都无问题。

## 2026-09-11 硬件、专属帆面与静态实时检查

本轮补上按层级区分的10个运动组，修了支架封住轴销、横梁贯穿导杆、两个帆轴座/桅杆箍相撞、凸轮无轴孔、绞盘高度不贴甲板。支承绕开波浪，船体通过真实托架接到横摇轴。帆索现为从帆角切向进入绞盘并绕线，不能退回到一根伸进绞盘中心的直线。

最新46个姿态的运动组之间/运动组与固定件的表面检查未检出交叉；92个帆/端点/凸轮/导杆采样通过。144个源姿态与真实载片唱机转盘角组合也未检出交叉。对应散列与范围在 `review/G_optical_curator/ship_r2/checkpoint.json`。仍不认证同一刚体组内部全部配合、最小制造间隙或完整转运/拆解/取消流程。

订阅内置生图新增帆布织纹及罗盘纹样原图，位于 `app/assets/collection/art/G_AI/ship/`，提示词保存在本目录 `assets/`。`ship_sail_materials.py` 将它们烘焙成两套1024平方的颜色、金属度、粗糙度和法线贴图，供 Blender 和 glTF 使用。纹样以实际帆面坐标定位，不能直接把烘焙后的非均匀UV图当作形状失真。它们是作者制作参数，不是实测布料数据。

实际GPU候选检查发现薄红色覆盖片闪烁，已改成帆材质内的染色带；退化的帆顶网格也改为单顶点三角拓扑。帆布/绣纹需要不同金属度，现只对 `ShipMainSail/ShipJibSail` 接通已有贴图和正确通道，旧 G 材质默认不启用。G0的73个表面、6类材质隔离回归通过。

`G_optical_curator_ship_candidate.glb/.json` 是独立 **静态几何/PBR候选**，保留现在主G中的G0/G1。`review/G_optical_curator/ship_r2/runtime/after_close.png` 和 `after_desktop.png` 是实际GPU场景；还看得到部分帆面斜向明暗块，需要区分阴影与法线原因，不能视为美术完成。新实时帆轴、波浪、帆索驱动尚未接入，此候选沿用旧共用形成效果临时显示形体，不得据此宣称分镜特效已实现，也不要晋升主G。

专属 `fabrication_storyboard.png` 已出：读取→支承/龙骨→船壳分区封合→织帆→潮汐→归位后逆向回收。图中有偏强的中心光束及浮动辅助线，落地时只保留依附真实机构的低强度光迹。底座/唱片尺寸仍取真实资产，生成图的比例漂移不作更改依据。
