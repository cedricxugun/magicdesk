# 机头内部与拆解返工

2026-09-10。用户再次指出拆解挤成一堆、机头内部过于简单。本轮按内置生图的 [结构稿](structure_and_explode_target.png) 重做内部和装配关系；图稿是制作参考，实际结果在 `review/G_optical_curator/service/`。

## 实体结构

- 三瓣可拆的曲面瓷壳；为侧向耳轴、颈部和驱动器开真实孔，底盖的颈部开口延伸成可滑出的槽。
- 分开的前镜筒、八叶快门盒、曲面表情显示模组、承力骨架、控制电路板、铜散热模组。
- 快门的环形齿轮、减速电机、小齿轮和八组驱动连杆随叶片动作；连杆端点来自实际铰接点。
- 骨架含耳轴、滚动轴承、颈部套筒和桥架；电路板有处理器、外围芯片、焊盘、铜走线、插座、绝缘线束和可断开的插头。
- 独立下投射器与表情机头保持独立姿态。原片尺寸、ID、原底座和正常镜头不变。

## 拆装逻辑

所有轨迹存在 `blender/collection/curator_service_layout.py`，写入模型 JSON，运行时按原位与轨迹节点求姿态。不能恢复旧环形盘架的通用径向偏移。

1. 读取臂先沿活塞轴抬离套筒，再向外移，给盘匣让路。
2. 六组唱片与托架先展开高度，再进入左右各三行，最后在各自位置松开唱片。直接把斜盘同时推到同一个平面已实测会穿插。
3. 承力柱、臂段、腕部按先后解开，腕部需同时避开下投射器与前臂的空间。
4. 上方瓷壳先离开；光学与电路模组再退出装配轴并错开展示。散热件先退出后方，再绕到下方展示位置。
5. 底盖随外壳先脱离：先松开唇口，再沿颈部开槽向后滑离腕部，最后降下。内部模组在瓷壳让开后再抽出；组装严格反向。

G 的拆开约 4.55 秒、收回约 3.85 秒；不改变其他装置的节奏。近景检查镜头只用于检查图，整机拆装使用原固定镜头。

## 光照的真实边界

应用场景有三盏实时面光源及阴影、HDR 环境反射、屏幕空间环境遮挡与间接光。G 的吸附、读取和构建有局部点光源。眼睛、光丝和光轨自身发光使用材质；头部另有弱点光源辅助照亮近处结构，不能把发光贴图等同于全局照明。透明桌面并没有自动读取现实桌面的照明。

## 检查与限制

`curator_service_take.gd` 保存整机固定镜头、近景、回装位置和画布边界；`check_curator_service_sweep.py` 用同一次 take 检查拆装过程中的新增三角形交叉与展开终点。初始接触对会单独保留，不得据此声称全部内部加工间隙已通过验收。动作采样、脚本检查、检查图都不能替代最终视觉验收。

当前还有整体材质、内部精致程度、其他五件藏品和完整构建/回收效果需要继续精修。不得把这一轮交接写成全套完成或 AAA 达标。
