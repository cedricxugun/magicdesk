# 潮汐帆船 R3：可见的齿轮—凸轮—摇臂波浪机构

用户否定R2的海浪机构精细度及可见运动。R2完整源和检查包仅保留为功能基线，不晋升主G。

`wave_drive_design.png` 是本轮内置生图设计目标：前侧可见啮合齿轮、共用连续轴、三个120°错相偏心轮、滚轮摇臂、连杆和直线导向波浪架。生成图的齿数、轴线与比例不能直接当作工程证据，必须以三维源校正；船体、桅杆、帆面和总安装高度沿用当前实际模型。

## 初步数值方案（场景单位，不是毫米）

- 标准20°渐开线外齿轮，模数0.003，齿数18/36；节圆半径0.027/0.054，中心距0.081，外啮合反向2:1速比。留制造感侧隙，最终以网格扫掠检查。
- 凸轮轴沿前后方向，中心A=(-0.035,0.125)（X/Z平面），偏心0.009、盘半径0.024，滚轮半径0.006。
- 摇臂固定支点P=(0.010,0.150)，输入臂0.040、输出臂0.068；用两圆交点闭合求解滚轮接触。输出杆长0.035，滑架X=0.088，保持实际销轴/球接端点连接。
- 数值扫一圈得到输出架Z约0.17450–0.20634，行程0.03185，约为旧0.012总行程的2.65倍。波浪几何将相对架体重新定位，避让船底；这还不是完成的三维碰撞证明。
- 同一轴的三个凸轮相位0/120/240°；不能三个轮各自旋转而轴不动。机械运动以连续相位积分驱动。

尺寸关系参考 KHK 厂商技术资料：https://khkgears.net/pdf/2023/spur-gears.pdf 。产品源模型的包围盒、齿形啮合、连杆、支承、传动和真实唱机避让仍需实际验证。

当前已创建独立R3组件，接入运行时、完整可编辑G源及日常Mac包。源 `blender/collection/G_ship_r3.blend`；主源/GLB已通过带备份的开发检查点晋升，见 `review/G_optical_curator/ship_r3/promotion.json`。

## 实际证据与边界

- `mechanism_check.json`：91源帧，各运动组互检，无表面交叉；接点约2.4e-8误差，不代表连续体积碰撞或动力学受力仿真。
- `gear_mesh_check.json`：201次实际齿面扫掠；有约0.000033–0.000099的侧隙，没有切入。
- `player_clearance.json`：6姿态×24唱盘角度避让检查。不是全部搬运动态的几何认证。
- `drive/gpu_qa.json` 与 `wave_drive.mp4`：原片读取、构建、运动、松手、收回、取消和全行程，实际GPU渲染。
- `full_take/`：3949帧完整可编辑源已烘焙并核对，含帆索/弹簧曲线。烘焙只对曲线变化插关键帧，变化前补持平帧，保留准确时序，避免为静止段重复写数十万点。
- `native/native_input_report.json`：机械铭牌→G、实体选片轮→帆船、调帆20度、压板begin/release、拨杆归片和中立状态；持续原生长按峰值尚未覆盖，不能用脚本GPU代替。

三片波浪分别重排轮廓/高度以避开滚轮与船体支承，中片缩小静态弯曲幅度；输出滑架的机械全行程均保留0.03185。回位弹簧一端固定、另一端随摇臂转动，两端挂圈与轴销有间隙。共享底座、船体与帆面尺寸未改。

本轮是开发精修检查点，不是AAA或用户美术验收。后续先F/I/J/K/L/M/N，再回G剩余。
