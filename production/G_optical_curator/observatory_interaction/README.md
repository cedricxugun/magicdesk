# 观测塔时间调节与共鸣：2026-09-10

本轮基于已接入的 G0 观测塔修改交互与反馈。G、其他五件藏品及整批精修尚未完成；没有新 Mac App 包，也没有原生鼠标操作或性能验收。

## 本轮修改

- 时间偏置从大范围绕圈改为中点两侧各30分钟，参数每秒最多变化1.0，避免输入事件让机构瞬移。时分针保持12:1关系。
- 原本已有按住加速；本轮将能量上升设为1.15/秒、下降0.85/秒，约0.87秒充满、1.18秒回落。持续积分运动相位，松手不重置机构姿态。
- 调整时，刻度盘下方的可见弧段亮起；持续按住时，天球出现窄光带，顶部红球增强但保留反光，并有弱局部点光照亮邻近结构。提示只在完整展示的G0启用。
- 回收、拆解或切换时立即清除交互叠层和点光，原唱片仍按完整路径回槽。

实体控件位置、共享底座、主体几何和其他藏品的参数范围未改。配置为 `app/assets/collection/observatory_interaction.json`。

## 实际画面与验证范围

[实际近景截图目录](../../../review/G_optical_curator/observatory_interaction/) 包含待机、调节、蓄力、共鸣、释放、恢复六阶段。相机为检查近景；不能据此称正常桌面尺寸足够清晰。

`tests/collection/observatory_interaction_take.gd` 在实际场景和实体控件驱动上回放。11项检查通过：限速跟随、调节光、蓄力与回落、回收清理、原片归槽。除了检查节点状态，还比较同姿态开关光纹的实际 GPU 图像，在盘面范围首次取得682个超过指定暖色亮度差阈值的像素（后续材质修改后的回归为862个；最新报告会随回放更新）。这证明近景里确有反馈，不能替代用户可读性判断。`--trace-debug` 图片仅供定位渲染问题，不是正式视觉结果。

完整主 take 为3805帧。`sync_observatory_interaction.py` 只更新九个观测塔机构轨道及实体控件灯光，其他对象运动指纹不变；改写前保存源备份。保存后的源比对5334个姿态，最大位置误差约1.2e-7、基误差约4.8e-7。报告在 `source_sync.json` 和上一级 `source_animation_report.json`。新 GPU 光层仍未烘焙，源文件不代表完整合成演出。
