# 原子之心风格 · 桌面机械装置设定
2026-09-08

当前交付是四个原创设定及动画、桌面交互规划。用户选择一个后，再制作模型、完整动画和 Windows EXE；本轮没有提前制作或宣称完成新模型、EXE。

## 风格依据
明确以《原子之心》这款游戏为参考。参考 Mundfish 对仿生、机械构造与复古科技的设计说明：[官方设计说明](https://mundfish.com/en/about)，以及[游戏官方介绍](https://mundfish.com/en/projects/atomic-heart)。

本轮具体表现为奶白搪瓷/瓷质外壳、镀铬与深色金属骨架、少量红色点缀、模拟仪表、可见内部机构，以及带生命感的动作。四个对象均为新创意，不是游戏已有机器人的复刻。目标是近距离桌面展示品质，外壳与内构都需要可观察。

## 四个方案

### A · 回声司仪 ECHO USHER
[完整设定图](A_回声司仪.png)

一台会礼貌“打招呼”的实验室播报装置。蛋形面罩、单眼虹膜和细机械手组成一个有性格的角色；靠歪头、指节动作和面罩打开表达诡异的亲切感。

- 唤醒：颈环依次抬起，虹膜对焦，手指轻扣两次。
- 招牌动作：面罩分片滑开，内部红色谐振核旋转，双手像指挥一样展开，然后鞠躬复位。
- 过载反馈：指针/虹膜快速响应，眼部转红，双手短暂失去协调后恢复礼仪姿态。
- 拆解路线：面罩向外、虹膜沿光轴、颈环沿竖轴、手掌与指节沿各自轴线散开；组装时颈部和核心先定位，再合面罩与手部。
- 建模重点：面罩曲面分缝、虹膜多层结构、重复指节与颈环。手部较精细，角色感最强。

### B · 孵日器 HELIOS INCUBATOR
[完整设定图](B_孵日器.png)

一个封存微型“太阳”的机械种子。闭合时像神秘实验样本，开启后成为由六片外壳、连杆和同心环构成的机械花。

- 唤醒：壳缝依次亮起，锁扣弹开，内部核心缓慢点亮。
- 招牌动作：六瓣外壳按节拍绽放，三层万向环分别转动，人工太阳抬起并脉冲。
- 过载反馈：万向环加速、锁定、产生一圈短能量脉冲，再慢慢收回。
- 拆解路线：六瓣外壳径向散开，连杆、轴承与环体分层展开，核心留在中央；组装从核心和支架向外恢复。
- 建模重点：六套重复瓣片与铰链、多轴环体、中央核心。整体变化幅度大，开花和爆炸图很有展示效果。

### C · 逆时水母 CHRONO MEDUSA
[完整设定图](C_逆时水母.png)

模拟计时器与水母形态结合的机器。钟形外壳下挂着铰接钟摆触须，内部两枚金属配重像某种机械器官。

- 唤醒：指针跳动、配重启动，触须逐根抬起。
- 招牌动作：壳盖抬开，计时轮转动，配重上下交换，触须形成星状姿态。
- 过载反馈：指针倒转，摆动逐层停止，再按相反顺序恢复，形成“时间倒流”的观感。
- 拆解路线：钟罩分瓣、表盘逐层分开、内部轴系纵向展开，触须按链节有序散开。
- 建模重点：少量重复铰接片、摆动轴、表盘和罩壳。四套触须需要控制运动范围与相位，生物感最古怪。

### D · 偏心方舟 PARADOX CABINET
[完整设定图](D_偏心方舟.png)

一个斜着悬在机械支架里的方匣，打开后露出红色内核与四只短机械手，像突然醒来的几何生物。

- 唤醒：万向支架把方匣摆正，面板逐个解锁。
- 招牌动作：六块壳板错序展开，四只折叠手探出、观察、行礼，内核独立旋转。
- 过载反馈：方匣快速偏转、内框锁止，红色核心短暂增强，然后回到偏心姿态。
- 拆解路线：壳板沿六个方向展开，框架梁、轴承、机械手与核心分层浮起；支架和底座保持结构关系。
- 建模重点：有规律的面板、框架和重复机械关节。爆炸图与组装过程最容易表现清楚的工程层次。
- 已修正图中支架在展开/拆解状态的连续性，作为后续机构设计约束保留。

## 共同的底座交互
底座保持不动，上部模型通过独立转台旋转。底座正面六个按钮始终容易点击，建议功能为：旋转/暂停、唤醒、招牌演出、过载、拆解、组装。最终符号及提示按选定方案统一。

按钮要有按下行程、边缘提示灯、对应机械音与动作反馈。可通过悬浮提示解释功能；功能文字属于界面，不把大量小字建成模型。

## “爆炸拆解”如何做成真实效果
这是可逆的机械爆炸图：零件快速向外释放、带少量旋转和惯性，随后稳定悬停，仍能看清内外层关系。组装时从核心、骨架到外壳依次吸附归位，最后锁扣落位。

- 每个需要拆出的组件都是真实独立模型，有装配变换、拆解变换和明确轴心。
- 小螺钉可归并在所属零件中，避免噪声与大量无意义物体；主要零件/重复关节要真实可拆。
- 底座与按钮保留，以便在拆开状态继续点击组装。
- 不靠切换两套完全不同的外观假装拆装。零件总数与归位姿态应保持一致。
- 动作中途重复点击、拆解途中组装、组装中再次拆解，都从当前姿态平滑处理，避免突跳、穿插、遗失零件。
- 静止展示与爆炸展示分别适配取景范围，避免飞散部件被软件边界裁切。

参考节奏可从快速释放约0.2秒、展开稳定约0.8–1.2秒、组装约1.5–2.5秒起步；这是设计建议，最终随所选结构实际调试。

## 完整动画范围
至少包括启动/唤醒、待机循环、招牌动作、过载及恢复、拆解、拆开悬停、重新组装、休眠/关闭。上部转台旋转与这些动作独立控制，按钮不随模型转走。

选定后先用实际灰模与动画验证机构，再完成材质与细节，并逐步在 Blender 显示过程。设定图中的形状和拆分需要转成统一三维结构；图本身不是已经验证的CAD图纸或可播放模型。

## Windows EXE 目标
按桌面摆件来制作：运行后模型坐在带按钮的底座上展示，支持拖动摆放、缩放、旋转暂停和完整动作反馈。透明背景/无边框展示为目标，交互区域要与桌面操作合理分开，并提供明确的收起和退出入口。

可执行程序内置所需模型、材质、动画和音效，运行时不依赖打开 Blender。当前还未选择引擎或开始打包；模型确定后根据渲染质量、透明窗口与桌面交互的实际验证决定实现方式。
