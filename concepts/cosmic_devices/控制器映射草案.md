# M / N · 控制器映射草案

最新 v3 方向：M 的场内对象改为三颗公转行星，原投料键改为重构键；N 改为异形裂口，原圆虹膜开门语义改为骨片与薄膜联动。图稿尚未全部统一，不把此表当作已经通过的实际面板验收。

当前设定图的按钮并非全部正确。部分沿用了 HELIOS 图标，部分专属控制器未完整出现在每帧；因此不能直接从生成图推断功能或制作命中区域。此表先锁定功能分工，后续要将所有正式状态图、拆解图和实际操作匣统一到同一份映射。

外部底座不变，电源与关闭入口保留左右端的固定位置。中间操作匣按原面板允许空间设计。表中的中间五区是布局参考；每款有四个操作组加一处状态显示，不是五个都可点击的圆按钮。

## M · 星噬仪

| 区域（从左至右） | 实体形式 | 行为与反馈 |
| --- | --- | --- |
| 固定电源 | 小型电源触点 / 原固定位置 | 唤醒供能或退场休眠；不等于退出 App |
| 1 轨道 | 滚花调节轮 | 切换有限公转节奏，轨迹连续变化；不会让物理零件转速失控或退出 |
| 2 星噬 | 有护罩的短锁杆 | 公转 → 螺旋内落 → 依次吞噬 → 稳定吸积；反向请求受控收束。锁杆到位有机械锁扣反馈 |
| 3 重构 | 矩形短行程键 | 结束吞噬，按灰、蓝、带环三颗行星的原身份重建并回到轨道；进行中不叠加第二套行星 |
| 4 拆装 | 中位复归的双向拨杆 | 向外拆解、向内组装；活动场先退场再拆，途中反向从当前姿态接续 |
| 5 状态 | 小型场稳定度表 | 只显示状态，不接收点击，不占据可操作键的命中区 |
| 固定关闭 | 最右侧红 X | 完成退场与必要收拢，熄灯后关闭 App；唯一明确的退出控件 |

## N · 裂隙回廊

| 区域（从左至右） | 实体形式 | 行为与反馈 |
| --- | --- | --- |
| 固定电源 | 小型电源触点 / 原固定位置 | 唤醒供能或结束连接后休眠 |
| 1 桥接 | 连动的双片裂口拨件（一个控制组） | 两端骨片扭开、黑膜回卷、建立连接；反向请求闭桥。两片拨件有错峰的小行程反馈 |
| 2 相位 | 带档位的调节滚轮 | 在有限档位间改变对准与喉道演出；不任意扭曲门的真实几何 |
| 3 探针 | 独立短行程测试键 | 只在桥稳定且探针就绪时启动一次穿越；进行中重复点击不给第二颗完整探针 |
| 4 拆装 | 中位复归的双向拨杆 | 先收回探针、断桥、收膜并合骨片，再拆；反向组装按当前状态接续 |
| 5 状态 | A / B 两枚小指示镜 | 分别显示端点与桥接准备状态；不是两枚重复的开门按钮 |
| 固定关闭 | 最右侧红 X | 当前穿越受控收束，断桥、收拢并退出 |

上部展示旋转可通过共享菜单控制，不强行为所有模型保留一颗旋转圆钮。

## 目前不能宣称已验收的部分

- 尚未将这份映射逐帧落实到所有生成图；图片中的旧图标不具有行为定义效力。
- 尚未完成控制器真实网格、按压/旋转行程、实际命中面和相邻间距验证。
- 仪表不可点击、拆装不退出、穿越中不会重复发射等仍需实际实现和测试。
- 正式制作时先出专属操作匣及反馈关键帧，再建模、绑定动作和实机验证，不能把生成图上的相似圆钮当成全部功能已正确。
