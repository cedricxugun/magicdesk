# M 星噬仪 / N 裂隙回廊 · 最新方向

2026-09-09，按用户的新方向更新。M 正常运行行星，被激活后吞噬行星；N 的门体需要更怪诞。首批名单仍待用户最终确认。

## M · 星噬仪 / ORRERY OF COLLAPSE

保留 v2 开放式三磁极、直线滑台、线圈和后部校准板，物理机器不再改变成壳或蛋。改变的是中央场中的演出，因此 `M_开放收束_拆解.png` 仍对应同一硬件；模拟行星、黑洞和物质流不属于实体拆解件。

### 明确的四段演出

| 状态 | 画面与动作 |
| --- | --- |
| 正常公转 | 三颗身份清楚的模拟行星：小型灰色陨坑星、中型蓝白纹理星、大型赭色带环星，围绕弱白校准点沿不同倾角的轨道公转。没有黑洞 |
| 星噬起势 | 中央黑色边界形成，原公转路径平滑转入收紧的螺旋。灰星先被拉长、产生潮汐碎片；蓝星与带环星仍保持可辨认的完整形态 |
| 吞噬高潮 | 灰星和蓝星依次消失；最后的赭色带环星连同环带被拉成细长物质流，进入黑色核心。形成薄吸积盘与弯曲的后侧亮缘；碎屑朝内收束，不能画成向外爆炸 |
| 重构复位 | 停止吞噬，黑色区域退去。稀疏物质流与线构在原轨道位置重建灰、蓝、赭色带环三颗星，恢复各自身份与公转 |

建议完整星噬过程 7–9 秒：前 1.5 秒轨道扰动，1.5–3 秒灰星先入，3–5 秒蓝星跟进，5–7 秒带环星最后拉伸入核，末段稳定吸积。重构作为独立可触发的 3–4 秒动作，不能一键突然出现三颗完整行星。具体时间按视觉分镜调整。

### 动作与素材先行

先出四个主阶段及灰星/蓝星/带环星的特写关键帧。分别生成三颗行星的专属表面、裂解内部与碎片材质；制作吸积流、细丝、星环撕裂、重构遮罩和亮缘等素材。用 Blender 验证行星破碎或形变、片段方向及光照参考，再由 Godot 将有身份的网格、专属纹理、变形、粒子与折射组合为可交互演出。

不能靠缩小几个默认球、随机抖动和默认粒子表示吞噬；原轨道进入螺旋时速度和位置需要连续，行星数量与身份需贯穿整个循环。

### 控制器变化

原“送料键”改为“重构键”，因为现在演出的对象是场内行星。中间操作匣建议为轨道轮、带护罩的星噬锁杆、重构短键、双向拆装拨杆与非交互状态表；左右电源和红 X 保持固定位置。图中的旧符号还需要统一，不能据图宣称全部按钮已正确。

拆解前先停掉模拟场，确保三颗行星和黑洞视觉都退去，再拆物理磁极与滑台。关闭优先执行受控收束，最后熄灯；不会把正运行的场留在已拆开的机器上。

## N · 裂隙回廊 / SCHISM CORRIDOR

### 门体造型

废止普通圆形相机门/虹膜环。A 端为倾斜、细长的泪滴裂口；B 端为较低、斜向的三叶裂缝。两端形状不同，但都由错位的瓷质长骨片、可见多轴镍关节、金属拉索和黑色聚合物薄膜构成。闭合时像两段蜷曲的实验室骨架，开启时是骨片扭开、膜片回卷形成空间口。

怪诞来自轮廓、非对称关节和像反射动作一样的时序；不用牙齿、骷髅、血肉或动物表情。机体仍从共同底座上真实连接，不能成为两张漂浮贴片。

### 动作编排

1. 待机：两道弯曲接缝闭合，膜片低幅呼吸。偶有一片瓷骨轻微松开再扣紧。
2. 开裂约 2.2 秒：A 先扭开上部骨片，侧片错峰外旋；B 晚半拍沿不同轴线反向展开。黑膜沿边缘后卷，暴露不规则空间口。
3. 联通约 1 秒：两端不同轮廓间建立折叠空间喉道，内部透视与光学轮廓连续变化；从 A 看得见 B 的接收端，不是填满发光色块。
4. 穿越约 2 秒：同一枚红尖头、银前身、白中段、黑尾探针进入 A；A 外保留后半段，B 外出现互补前半段，直到探针完整到达 B。
5. 回缩：探针离开后，喉道变薄，黑膜先沿边缘收回，骨片像一次克制的机械反射按相反顺序闭合。底座和镜头不动。

### 对应拆解

必须以新版裂隙主图中的两套不规则骨片/关节为源，另出拆解图。旧圆门拆解只保留为历史，不适用于新版。拆解时无空间喉道：先关闭膜片，再显示瓷骨覆片、连续金属骨架、关节轴、膜片卡匣、支座与探针轨道；共同底座完整保留。

### 动作与素材先行

需要闭缝、开裂中段、喉道建立、探针半入半出、回缩和分件关键帧；黑膜的皱褶与边缘图、扭曲喉道轮廓、空间深透视、骨片内侧材质和接点光都需专属素材。Blender 验证多轴关节、膜片回卷与门体避让；Godot 负责门平面裁切、对端视口、状态机和实时合成。

普通圆环模板、直光线或不透明蓝色圆片不再是可接受的正式视觉方案。控制器的“开门”语义也同步改为两裂口联动，不继续沿用圆虹膜机的旧按钮图标。
