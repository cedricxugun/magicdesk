# M / N · 时空器具的动作与特效方向

两款都是科幻视觉装置候选，不是真实物理实验设备；尚未加入最终制作名单。底座保持统一尺寸，独立控制器放进同一操作匣区域。

## M · 奇点铸炉 / SINGULARITY FOUNDRY

观看重点：一个小范围、极黑的核心如何被机械收束场建立，周围物质怎样被拉入。黑洞外观不能退化为换成黑色的普通发光球。

1. 待机：屏蔽壳关闭，赤色检查缝低亮，场强指针轻动，送料臂停在安全位。
2. 建场约 5 秒：前 0.7 秒解除屏蔽锁；0.7–1.8 秒两片护壳沿真实铰链退让，三段约束组件对准；1.8–3 秒细光被压向中央，黑色核心边界形成；3–4 秒吸积纹理由疏到密，两送料臂分别注入短物质流；末段稳定在克制的薄光环状态。
3. 强演出约 6 秒：送料先错峰加密，吸积纹理转速与偏转逐渐增强；3–4 秒出现清楚的绕后弯曲亮缘与一轮被拉入的细丝；后半段退料、降速、回稳。绝黑区域仍保持清晰，不靠全屏白闪表达高潮。
4. 拆解：先结束投料、让场退去，再拆护壳、收束组件与送料臂。拆解的是器具，不把黑洞当作实体零件拆开。
5. 收势与关闭：停止送料 → 细丝收尽 → 光环变薄 → 护壳闭合 → 场强表归零。切换归档从这个封闭状态开始。

专属控制：压缩轮、带护罩坍缩拨杆、方形送料脉冲键、场稳定度表。各控制变化都有可见机械反馈与有界状态。

正式制作前需要的图：封闭、护壳半开、建场边界、稳定吸积、投料高潮、退场六帧；另外明确正面、侧面与倾斜视角下的核心轮廓。

实际美术资产：独立吸积纹理与流动遮罩、细丝/尘埃元素、亮缘与场边界图、送料触点材质、Blender 校准的曲线流或烘焙素材。Godot 再结合深度、遮挡与专属折射着色器完成实时合成。不能只用一个黑球、一圈默认粒子和随机噪声交付正式效果。

底座适配：收束壳沿中央安装座倾斜布置；整体高度目标 ≤1.35D、最大展开宽度 ≤1.5D，送料臂避开前面板和档案架。

## N · 虫洞回廊 / BRIDGE ENGINE

观看重点：两座错位机械环门如何建立连接，以及同一枚探针的连续进出。不是两个互不相关的发光圆圈。

1. 待机：两虹膜关闭，两环门沿前后错位方式收拢，探针停在近端轨道。
2. 通桥约 4.8 秒：0–1 秒两座关节座依次转到对准角度；1–2.2 秒内环转动、虹膜逐瓣打开；2.2–3.2 秒门边纹理由断续到连贯，门内出现对端装置的局部视景；3.2–4.8 秒单枚探针沿支撑轨道进入近门，从远门接续出现。
3. 强演出约 6 秒：相位轮带动两内环反向校准，桥喉轻微收缩并重新稳定；探针往返一轮，光沿真实环槽推进。交接时可以使用两份被门平面裁切的几何显示同一探针，但不能出现两颗完整探针。
4. 拆解：探针先归位，两门关闭，内环锁定；再拆两门卡匣、虹膜片包和万向轴座，歧管与公共底座保留。
5. 收势与关闭：探针完全离开门面后结束连接，门内视景退去，虹膜闭合，两门回到收纳位。不能夹断探针或在中途突然显示完整第二颗。

专属控制：成对开门拨片、相位滚轮、桥接锁杆；门面和探针状态都要有清晰反馈。

正式制作前需要的图：双门收拢、半开虹膜、连接形成、探针半入/半出、通桥高潮、断桥闭合；每个镜头保持相同门尺寸和探针身份。

实际美术资产：专属虹膜边缘图、相位纹理和遮罩、桥喉/视景畸变方向图、接点光与短尾素材、Blender 的虹膜与轨道动作参考。Godot 可以用对端视口、门面裁切与着色器实现连续视景，但视觉轮廓必须对照已出的图和资产，不能仅用两个默认圆环。

底座适配：两门前后错位并采用不同高度，单门外径约 0.40D、上部总宽目标约 1.15D，不为并排双门加宽底盘。
