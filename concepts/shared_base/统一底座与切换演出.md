# MagicDesk · 统一底座与机械档案匣

2026-09-09 设计目标与历史选型记录。首批 F/G/I/J/K/L/M/N 已确认并接入本机开发构建，原 B 保留。下文的建议节拍与概念图不等于逐项完成；当前证据和未完成的美术验收见 `../../production/batch1/WORKLOG.md`。

## 已确认的方向

一个 App，一个长期存在的底座，可以收藏和切换多种装置。继续参考《原子之心》的复古未来实验室、仿生机械、奶白瓷壳、镀铬骨架与红色仪器细节。风格参考不等于照搬游戏道具。

**统一底座主体，不统一所有按钮。** 共用底盘外壳、外径、桌面锚点、上部安装接口和档案匣机关。每款模型有自己的操作匣：按钮数量、几何形状、行程、图标、声音与行为均可变化；可以使用按键、拨杆、旋钮、触片。七个圆钮仅属于当前 HELIOS，不是新模型的模板。关闭入口保持明确，档案匣入口不随模型改变位置。

## 已选择的展开结构：机械档案匣

2026-09-09 用户认可画廊中“机械伸出来”的结构。保留弧形盖板、折叠连杆、实体玻璃铭牌与索引轨道；接下来细化这套机构。认可的是展开结构的方向，不代表生成图已满足共同底座的尺寸或内部收纳要求。

入口改为底座左前侧上沿的一小段**弧形金属压条**，远离右侧关闭入口。平时与原有环沿齐平，连续的拉丝纹理跨过接缝；不放独立的圆形菜单键、箭头或常显菜单图标。鼠标靠近后，接缝下出现一条短红光，沿压条扫过，局部锁舌轻微试探，并可显示简短的“展开档案”悬浮提示。

点击这段压条后，它向内压入，弧形盖板沿导轨退入底座，一段折叠连杆将铭牌架伸到左前方。烟色玻璃与镍边框的档案铭牌储存在索引转鼓里，前方至多六张错层扇形展开；每张都通过小铰链连接到轨道，具有模型轮廓、字母和短名称。原图中的十二张是容量示意，最终按实际制作清单验证收纳，不给未实现候选显示可切换入口。它们是机器里的实体索引片。牌架不经过花瓣/翅膀扫掠区，也不挡住操作面板和关闭入口。最终尺寸与相交关系必须在灰模中验证。

- 展开阶段建议 0.8–1.0 秒：局部压条按入 → 锁舌旋开 → 盖板退让 → 折叠支架伸出 → 牌片依次立起。
- 浏览时暂停上部展示旋转；未选择前，当前模型仍在底座上。蒸汽可继续自然消散。
- 悬停某一铭牌：只将该牌抬起约 8–12°，边缘点亮，牌内呈现小型线框姿态；其他铭牌不跳动。
- 点击铭牌就选择，不需要另加确认按钮。点击当前款或再次点击压条则收起。
- Esc 或点击牌架外的空白处取消；不改模型、不吞掉关闭操作。
- 超过六款时通过滚轮或拖动实体索引轴浏览；转鼓将后方铭牌依次送到前方展示位，仍然直接点击牌面选择，不加左右箭头。

### 入口的点击反馈

建议节拍：前 0.10 秒压条压入约 0.003D，同时发出短促弹簧锁扣声；0.10–0.25 秒局部锁舌旋开、两段暗红接点依次亮起；0.25–0.60 秒盖板退让、连杆带着收叠牌架伸出；0.60–0.95 秒牌片逐张翻立，最后一张到位后发出一声轻锁止。整段只有局部机构运动，底座主体与相机不震动、不放大。

选牌时，被选铭牌先小幅压回卡位，再被读取槽拉入；牌边刻线亮起，光沿真实导轨接点传回安装口，然后开始模型归档。收起则牌片先叠拢、连杆回折、盖板复位，压条最后恢复齐平。反馈来自弹簧、连杆、读槽和触点，而不是屏幕按钮的缩放或全屏闪光。以上为动作目标，尚未实现。

### 共同底座上的下一次展示

入口收起、悬停、压入、牌架展开、选牌、模型切换六种状态必须用同一份真实底座网格与同一相机输出。图里的旧圆形菜单键只属于早期探索；入口以本节的环沿压条为准。不得在不同状态或不同模型下重画、加厚或放大底座来腾出空间。

## 模型交接：归档与重铸

视觉核心是“同一台装置调用不同的机械实体”。固定镜头和底座尺寸，变化只发生在上部装置及其专属操作匣。下面是普通稳定状态下约 3–4 秒的节奏目标；拆解状态需先完成安全收束，不能硬塞进相同秒数。

| 阶段 | 画面与机械动作 | 交互约束 |
| --- | --- | --- |
| 点选 / 准备 | 目标铭牌扣进档案读槽，接点依次亮起。后台准备目标资源；当前模型还在 | 未准备好前不抹去当前模型；用户可取消 |
| 0–0.7 秒：收势 | 当前装置结束招牌动作，沿自己的路径进入紧凑交接姿态。轨道粒子收束，蒸汽停止发射并继续散去 | 收势期间停止触发新的模型动作；关闭仍有效 |
| 0.7–1.45 秒：归档 | 底座三个内嵌扫描头抬起。极薄的红色水平扫描层自上而下经过模型，扫描过的表面转成短促金属线与细粒，沿竖直磁力丝回收到安装口 | 必须有明确的扫描边界，不能整个模型一键淡出或瞬间缩成小球 |
| 1.25–1.8 秒：换匣 | 当前控制器缩回面板，弧形操作匣解锁翻入底座；新操作匣沿同一导轨转到正面，实体控制器伸出 | 根据真实机械遮挡完成更换；避免当着用户把圆钮变形成拨杆 |
| 1.45–2.55 秒：重铸 | 安装口先亮出目标安装骨架。扫描层由下向上重建金属内构，再补齐瓷壳与玻璃；新装置保持可辨认的几何结构 | 底座、窗口位置、镜头完全固定，不用屏幕闪白遮掩切换 |
| 2.55–3.4 秒：到位 | 锁爪压紧，新操作匣指示灯确认，新模型执行独有的短招呼。档案铭牌架收回 | 新模型和控制器均到位后恢复点击 |

声音建议：低沉锁芯咔哒、短距离导轨摩擦、递降归档共振、递升重铸共振、最后一声清晰锁止。避免每次切换都爆炸或持续轰鸣。动效减弱模式保留收势、机械换匣和短扫描，不做强闪烁。

- B 孵日器：结束过载、组装并闭合六瓣；到位后缝隙逐段点灯。

## 对当前代码的影响

当前 `app/main.gd` 的标题、动作分支、六瓣控制、万向环和状态变量都属于 HELIOS；`core_vfx.gd`、`cinematic_effects.gd` 等还直接引用太阳核心与花瓣节点名。因此下一轮需要先建立共享底座与模型适配层，不能只替换一条 GLB 路径。

建议结构：共享 `DeskHost` 管窗口、相机、底座、拖动、声音总线和档案匣；每个 `ModelModule` 提供模型、操作匣、动作定义、特效接点、完整显示边界与 `stow / arrive / shutdown` 演出。HELIOS 先作为第一套模块迁入，现有七钮和特效保留。

输入按当前操作匣的实际几何命中，快捷键从动作定义生成，不把 `1…7` 当作所有模型的硬约束。相机按统一底座比例校准，导入时验证模型动作包络与牌架的空间，运行时不自动缩放。

切换应是单次事务：目标加载与预热通过 → 当前装置收势 → 归档 → 替换 → 到位。旧模型保留到新模型确认可显示；失败时恢复旧模型和旧操作匣。重复点选不叠加多套切换，退出请求优先，过时加载回调不得重新唤起已关闭场景。

## 选型后的第一步

先做共享底座、铭牌架、两种操作匣的灰模与一进一出演出验证，再制作用户选中的新装置。验收实际连接、牌片可读可点、最宽展开状态避让、拆解中切换、加载失败恢复及关闭；设计图不代替这些验证。
