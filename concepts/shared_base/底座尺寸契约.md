# 共用底座尺寸契约 · 源模型基准

2026-09-09。响应“所有模型使用同一个底座”的要求。

## 先纠正图的用途

各张生成图曾独立重画底座，外壳厚度、阶梯和面板比例不完全一致；构图角度也不同。它们只能作为上部装置与专属操作器的造型探索，**不能把每张图的底座分别建模，也不能把画面中的像素尺寸作为真实比例**。当前图仍不是经过统一相机校准的等比例产品渲染。

## 唯一尺寸来源

从 `app/assets/helios_model.glb` 的 `BASE_FIXED` 子树读取实际 POSITION 顶点和节点变换；测量脚本为 `tools/measure_shared_base.py`，完整结果在 `base_measurements.json`。

| 项目 | 当前实测值（场景建模单位） | 处理方式 |
| --- | --- | --- |
| 底座左右外径 D | 2.740000 | 归一化为 1D，所有模型共用 |
| 含前方控制器的总深度 | 2.809712 | 按真实原件保留，不用外接框误当圆盘直径 |
| 固定底座整体高度 | 0.670608，约 0.245D | 含固定装饰，不能为新装置加厚 |
| 原件最低 / 最高 Y | 0.005000 / 0.675608 | 同一摆放平面与固定底座范围 |
| HELIOS 闭合状态总高 | 3.788000，约 1.382D | 新装置高度比较的现有参照 |

这些是数字场景单位，不是可生产的实物毫米尺寸。外径取左右方向的壳体直径；前方按钮和面板会超出圆盘在 Z 方向的包围范围。

现有建模脚本中前方瓷质面板采用半径约 1.354、Y 约 0.155–0.46、前方约 ±63° 的弧段；这给出操作匣的初步定位参考。由于后续固定装饰已并入网格，最终拆分边界应直接从当前网格提取，不能盲目重跑早期建模脚本。

## 哪些固定，哪些可变

- **固定**：底座外壳与阶梯、直径、高度、桌面位置、上部接口坐标、档案机关入口、关闭入口位置。运行时只存在一份共享底座实例，禁止每个模型携带自己的完整底座。
- **可变**：规定面板区域里的操作匣，以及接口之上的模型和自己的安装支架。按键、旋钮、拨杆数量可变；它们必须在相同的控制器允许空间内。
- 操作器放不下时，减少数量、改变排布或将相关动作合并到拨杆档位。**不放大、加高或拉长底座**来容纳它。
- 新增档案匣与换匣机构只允许形成一版所有模型共同使用的底座内部修订；外部固定尺寸仍遵守原基准，HELIOS 也迁到这同一个版本。
- 目前没有验证底座内部的可用体积。十二张铭牌转鼓、翻转操作匣和扫描头是否能同时收纳，必须做剖面灰模。放不进去时先改内部方案，不能把“科幻”当成忽略空间的理由。

## 上部装置的第一轮体量约束

以下是为了开始灰模而提出的包络上限，不是生成图已经满足的结果。高度从地面量，包含共同底座；展开宽度只指主装置，特效和档案架另计。

| 款式 | 建议闭合总高 | 招牌展开宽度目标 | 适配重点 |
| --- | --- | --- | --- |
| A 回声司仪 | ≤1.45D | ≤1.80D | 双手收回后不能压住档案架，减少肩部横向挤占 |
| B 孵日器 | 当前约1.382D | 保留现有实测动作 | 作为共同底座迁移基准 |
| C 逆时水母 | ≤1.30D | ≤1.65D | 触须最低处保持离底座与按钮的净空 |
| D 偏心方舟 | ≤1.30D | ≤1.65D | 支架脚落在同一安装面，偏转时不扫到面板 |
| E 织梦蛾 | ≤1.45D | ≤1.80D | 细长胸腔与四翼按统一 D 校准，不把底座缩小来显得高大 |
| F 拉格朗日天平 | ≤1.40D | ≤1.60D | C 臂落脚宽度、配重最低位和悬臂运动范围 |
| G 折维书匣 | ≤1.30D | ≤1.60D | 缩小封盖和页片跨度，控制分层高度，不增加底盘层数 |
| H 雷暴管风琴 | ≤1.45D | ≤1.35D | 五管围成浅弧、前后错位排布；不能为横排五管扩大底座 |
| I 回声海螺 | ≤1.30D | ≤1.50D | 螺壳沿深度布置，用内部铰链展开，不向两侧扩底盘 |
| J 汞芽温室 | ≤1.40D | ≤1.60D | 枝条展开后仍从统一中央安装座承载 |
| K 星图刻写机 | ≤1.05D | ≤1.55D | 双卷轴错层布置，横梁不能成为加宽底座的借口 |
| L 三相窥镜 | ≤1.35D | ≤1.50D | 三根潜镜采用三角排布，共用中央安装壳，不并排挤占底座 |

所有装置的安装几何在制作时以 D 归一化一次。之后模型切换、开合、拆装都保持相机与底座像素尺寸不变；不能依靠镜头自动缩放来掩盖超出包络。

## 接下来必须验证的内容

选定模型后，先在**同一个真实底座实例**上做上部灰模与操作匣，固定同一相机输出静置、最大展开、拆解、档案架展开四种状态。检查全周旋转及中途打断的运动包络，尤其是控制器行程、档案架避让与内部收纳。通过这一步再开始高精度建模。
