# 新装置 · 动画与操作设计

2026-09-09。以下为动作导演稿与机构方向，尚未建模、烘焙或接入 App。时间是建议节奏，不是实测结果。美术继续参考《原子之心》的复古未来实验装置与仿生机械；每款有独立动作和操作匣。

## E · 织梦蛾 / SOMNUS LOOM

**观看重点：从紧闭瓷质披风，变成会织光的四翼机械生命。**

| 动作 | 编排与机构 |
| --- | --- |
| 待机 | 两根触角缓慢交替探测；胸腔线轴轻转，四翼保持约 1–2° 的低幅呼吸。底座不参与起伏 |
| 招牌演出「织梦」约 4.6 秒 | 0–0.5 秒肩锁抬起；0.5–1.8 秒两片上翼沿各自双轴铰链先外旋再张开；1.1–2.3 秒下翼跟进形成上下错层；2.0–3.6 秒收放线轮将几条光丝依次张紧，织出由疏到密的图案；3.6–4.6 秒四翼轻合再张，图案像呼吸一样变形 |
| 强演出「共振」约 5.5 秒 | 蓄能时线轴反向预紧，翼尖仅小幅错相摆动；高潮让光丝波峰依次从胸部传向翼尖，触角短暂形成放电桥；最后退回稳定织纹。不能用全翼高速扇动制造飞行或用烟遮住翼片 |
| 拆解 | 光丝先回卷、肩锁解开；四翼按各自铰轴径向分离，再将翼根线轴、肩环、胸腔护片分层显示。头部、触角与胸部的装配关系明确 |
| 组装 / 关闭 | 肩环与线轴先归位，四翼落轴，瓷片扣合，重新张丝；关闭则先收丝、下翼内折、上翼覆合，触角最后下垂 |

专属操作匣：成对翼形拨片触发开合，滚花张力轮控制织纹松紧或切换几种织纹节拍，短行程梭形滑片触发共振；拆装可用独立双向锁杆。旋钮的实际连续控制范围需实现时限定，不能让电机无边界叠加转速。

制作难点：四翼相互避让；光丝端点跟随翼骨真实连接；伸缩时不能穿过瓷片。可先用少量确定的样条验证，图中的密集光丝不等于全部要逐根模拟。

## F · 拉格朗日天平 / LAGRANGE BALANCE

**观看重点：一边是泪滴配重，一边是瓷质棱柱，机构越过平衡点后停在不合常理的位置。**

| 动作 | 编排与机构 |
| --- | --- |
| 待机 | 两个配重围绕不同轴线缓慢小幅摆动；表针跟随联动位置，C 形支臂保持固定 |
| 招牌演出「逆衡」约 4.2 秒 | 0–0.6 秒制动爪抬起；0.6–2.0 秒双平行连杆展开，将右配重送向外侧，左配重同时上提；2.0–2.6 秒在平衡点前减速；2.6–3.3 秒越过平衡点并停止；3.3–4.2 秒指针一次过冲后回稳，中央细光基准线仍垂直 |
| 强演出「失重拍」约 6 秒 | 连杆依次改变相位，两个配重沿真实关节轨迹完成一段反向交换；最强处短暂停在约 90° 相位差，机械刹片咬合后释放。所有重量始终有杆件连接，不把配重凭空放飞 |
| 拆解 | 先归零制动，再抽出销轴；配重沿悬挂轴下移，连杆按前后两层拆开，C 形瓷盖沿弧段退出，内部金属脊梁保留为参照 |
| 组装 / 关闭 | 脊梁与连杆先定位、销轴回插、配重挂接、瓷盖闭合；关闭时降低摆幅，配重都回到低位，表针归零后熄灯 |

专属操作匣：制动拨杆、带刻度的大配平轮、方形脉冲键，以及小幅度指针表。表盘是状态反馈，不伪装为可点击按钮。改变配平轮时改变目标姿态或演出模式，仍遵守安全运动范围。

制作难点：闭环连杆的关节解算与两配重的扫掠避让。图中的侧伸姿态只是目标，灰模必须证明连杆连续，不可用拉伸杆件掩盖错误机构。

## G · 折维书匣 / PALIMPSEST ENGINE

**观看重点：厚重封闭的机械书，展开后成为层层错位的空间结构。**

| 动作 | 编排与机构 |
| --- | --- |
| 待机 | 书脊三个小锁片缓慢接力点亮，封盖保持约一条发光薄缝；索引针偶尔在缝边探出后退回 |
| 招牌演出「折维」约 4.8 秒 | 0–0.5 秒红色封扣退开；0.5–1.4 秒双封盖展开到约 65°；1.0–3.1 秒六片刚性内页以约 0.2 秒错峰绕书脊分层翻出；3.1–4.0 秒各页的偏心套筒微升，形成阶梯状空间；4.0–4.8 秒页内镜片之间点亮小型几何线构，并由索引针沿边巡检 |
| 强演出「重写」约 6.2 秒 | 外封盖固定，六页按连续波一次合拢又展开，线构先擦除再反向绘制；3–4 秒页片全部立于不同方位、线构最清晰；之后逐页回落。重点是页片秩序变化，不是绕核心乱转 |
| 拆解 | 索引针缩回、镜片关闭；六页保持编号和角度沿自己的铰轴抽出，隔套依次分离，双封盖退出最外层，书脊与中央安装关节始终可辨 |
| 组装 / 关闭 | 内层轴套先归位，页片由内到外落轴，索引针完成一次检查；关闭时页片按从外向内的顺序叠合，封扣最后啪嗒锁止 |

专属操作匣：页形拨片、带棘齿的索引轮、护罩下的红色封存锁。拨片可分别对应展开、换页序、回卷；不要求与蛾的控制器数量一致。

制作难点：页片与书脊的轴心、厚度和错层高度。铰链不能在图中展开后消失；先验证六页碰撞与翻页途中反向收拢，再增加索引针和光构。

## H · 雷暴管风琴 / TEMPEST ORGAN

**观看重点：五根不同高度的真空谐振管，以机械节拍依次积蓄、放出受控雷暴。**

| 动作 | 编排与机构 |
| --- | --- |
| 待机 | 五管内部低亮灯丝错相呼吸，压力针极小幅抖动，歧管只保留细微逸散 |
| 招牌演出「风暴和弦」约 4.4 秒 | 0–0.6 秒风门锁打开；0.6–1.4 秒三片背部导流罩依次张开；1.1–2.8 秒五管从低到高点亮，每管的电极臂对准真实接点；2.8–3.4 秒电弧沿 1→3→5→2→4 的通道节奏接力；3.4–4.4 秒压力表回落，导流罩停在展示位 |
| 强演出「雷暴齐奏」约 6 秒 | 先以两管交替蓄能，3–4 秒五管形成一次同步强脉冲，电弧分叉仍连接电极；末段管内光由高到低逐根熄退，最后短促泄压。避免不间断高亮闪烁 |
| 拆解 | 先关闭放电并卸压，五个整管卡匣按高度依次从歧管插座抬出，电极臂折回，背罩沿自己的铰链退出；玻璃管与瓷环先作为完整卡匣拆解 |
| 组装 / 关闭 | 卡匣逐根落座、卡环锁紧、管内自检灯依次走过；关闭时风门收合、五管退亮、压力表归零，底座保留短暂余光后退出 |

专属操作匣：五枚短触键对应五管视觉/音色反馈，风门旋钮调整演出节拍档位，短泄压拨杆触发收束。音量和静音仍可通过共享菜单控制；短触键不是另做一整架钢琴。

制作难点：透明玻璃内外层排序，电弧真实端点，五通道声音与光的同步。先实现固定几种确定的演出，不承诺任意音频分析或真实流体乐器。

## I · 回声海螺 / HELIX AUDITOR

**观看重点：螺壳像耳朵一样听，像呼吸一样逐片打开。**

- 待机：喉闸保持小缝，前方膜片低幅收缩，整机只在安装关节上缓慢偏转几度。
- 招牌「听潮」约 4.5 秒：前 0.5 秒开喉闸；0.5–2.5 秒六段瓷壳沿螺旋顺序抬起，每段仍连在内脊梁；2.5–3.5 秒同心膜片从内向外做一轮位移波；最后音叉接力发亮，声音衰减而壳体停在展开状态。
- 强演出「回声折返」约 5.5 秒：喉口音叉先蓄能，一道克制的声波轮廓离开口沿后返回；膜片与音叉倒序响应。光圈只是声场轮廓，不做魔法阵或大范围持续震屏。
- 拆解：先关闭声场，喉口膜片沿共同轴退出，壳片沿自己的销轴分离，音叉卡匣退开，内脊梁与支架留下清晰参照。组装反向进行。
- 收势 / 关闭：先降低膜片振幅，壳片由尖端向喉口合拢，喉闸最后合上；到位招呼是一次轻微偏头和短音。
- 专属控制：调谐轮改变有限几种共振节拍，喉闸拨杆控制张合，两枚触片分别触发听潮与折返；不需要麦克风输入。
- 底座适配：用螺壳的深度容纳机构，不能拉长底盘；验证喉口伸出后对前面板的遮挡。

## J · 汞芽温室 / MERCURY HERBARIUM

**观看重点：三株封闭机械花依次“生长”，红色脉冲在毛细管里往返。**

- 待机：三芽呼吸相位错开，叶片小幅转向，红色管道内只有偶发的弱脉冲。
- 招牌「萌发」约 4.8 秒：0–0.7 秒泵杆压入并点亮管路；0.7–1.8 秒主干用真实套筒升高；1.5–3.0 秒枝条沿肘关节抬起；2.2–4.0 秒三个芽以 0.4 秒错峰打开瓷瓣；末段叶片朝花芯逐片转向。
- 强演出「授光」约 6 秒：脉冲先从根部依次上行，三个玻璃花蕊形成一次顺序明亮脉冲，再沿毛细管回流。无需全屏花粉或真实流体求解；有限管道里的材质流动即可表达。
- 拆解：先收叶与停泵，三个完整芽卡匣从枝头抬起，叶片沿小铰轴退出，主干瓷护片打开；枝条金属骨架与软管连接关系要能读懂。组装先管接头、后护片与花芽。
- 收势 / 关闭：三个花芽逐个闭合，叶片贴干，套筒退回，红光回到根部后熄灭。到位只让最高一枚芽试开一条缝。
- 专属控制：三枚芽键可分别点亮对应枝条，泵送杆触发生长演出，旋钮切换脉冲节奏。整机姿态仍由有界动画驱动。
- 底座适配：枝条在统一中央安装座上展开，不给每根枝条单独扩出一块底座。

## K · 星图刻写机 / ASTROGRAPH SCRIBE

**观看重点：盖板退开，卷轴匀速送带，三支细刻针在不同节拍上工作。**

- 待机：检查窗内的星图带低速移动；一支刻针偶尔试探，左右卷轴根据收卷半径呈不同角速度。
- 招牌「刻星」约 4.6 秒：0–0.6 秒解锁；0.6–1.6 秒双盖先外移再抬起，避免扫过针架；1.4–3.8 秒三支刻针以点、短线、长线的顺序落下，卷轴间歇送带；最后针头一起抬起，露出新刻的局部图案。
- 强演出「流星行」约 5.5 秒：逐渐加快送带，三臂形成一轮交错快节拍；高潮后回车拨杆弹回，金属带短距离回卷到清晰展示位。不让刻针无约束乱碰，也不把图案变成浮动屏幕。
- 拆解：先抬针、停卷、给带材留松弛，三个针架沿导向轴分层升起，双卷轴从对应轴心退出，盖板后退；带材可先回到收卷盒，避免悬空断带。
- 收势 / 关闭：完成当前笔画后抬针，收带，盖板反向落下并闭锁；到位后回车杆短促跳动，窗口出现一个光点。
- 专属控制：三枚短键调用不同刻写片段，回车杆执行回卷归位，送带滚轮切换节拍档；不把其做成文本输入程序。
- 底座适配：卷轴采用前后错层，低矮横梁的投影不能迫使底座加宽。需检查双盖展开后与档案架的净空。

## L · 三相窥镜 / TRIPHASE OBSERVATORY

**观看重点：三个潜镜头拥有不同的搜寻节奏，最后忽然协同对焦。**

- 待机：短头先看左侧，中头迟半拍跟随，高头偶尔俯视另外两个；小范围关節动作与虹膜收缩建立性格。它们只执行虚构观察演出，不读取摄像头或桌面内容。
- 招牌「三相对焦」约 4.3 秒：0–0.8 秒镜颈分次伸出；0.8–2.2 秒三头沿限定关节范围搜索；2.2–3.0 秒虹膜依次缩小，头部对准同一个受支撑的光学标靶；3–4.3 秒三束细光交汇，随后各头保持不同的小幅呼吸。
- 强演出「视差追逐」约 5.8 秒：标靶沿短支撑弧移动，三头依次追随；中段光束轮流亮起，最后同时截获目标，再散开。不要让镜颈互相穿过，也不做高速监控探照灯。
- 拆解：先灭光、缩镜颈，三个完整镜头从颈部轴上取出，再显示伸缩筒、万向接头与底壳；三组零件始终保持各自身份。组装从颈轴到镜头再到外壳。
- 收势 / 关闭：三头围拢，虹膜闭合，镜颈由高到低收回；到位招呼是高头先抬起，另两头再看向它。
- 专属控制：三枚镜头选择拨键、共同调焦滚轮、虹膜拨杆；控制模式切换不允许把某头从当前姿态瞬移。
- 底座适配：三角形布置镜颈，使用同一中央安装壳；展开宽度目标不超过 1.5D。

## 与旧方案一起选

| 编号 | 核心观看体验 | 下一款制作取向 |
| --- | --- | --- |
| A 回声司仪 | 面罩、虹膜、手势与礼貌动作 | 最有角色感，手指和表情机构较复杂 |
| B 孵日器 | 六瓣机械花与赤红核心 | 已有程序，作为共享底座迁移的基准 |
| C 逆时水母 | 多触须相位、配重与倒转计时 | 适合仿生节奏与待机观赏 |
| D 偏心方舟 | 匣体偏转、壳板与小机械手 | 适合明确的几何拆装和俏皮反馈 |
| E 织梦蛾 | 四翼开合与光丝编织 | 生物轮廓强，张开前后差异大 |
| F 拉格朗日天平 | 配重越过平衡点、关节制动 | 空间通透，机构本身是主角 |
| G 折维书匣 | 刚性页片形成空间建筑 | 从闭合到展开的结构变化最鲜明 |
| H 雷暴管风琴 | 多通道真空管与电弧节拍 | 适合声光同步，具有仪器感 |
| I 回声海螺 | 螺旋壳片与膜片共振 | 适合细腻的机械听觉性格 |
| J 汞芽温室 | 机械生长与三芽错峰 | 适合温和但异质的生命感 |
| K 星图刻写机 | 送带、刻针与回车节奏 | 适合精密劳动与短循环观赏 |
| L 三相窥镜 | 三头的独立性格与协同对焦 | 适合有幽默感的待机演出 |

优先建议 E 或 G：E 有生物性格与宽翼变化；G 与现有孵日器的轮廓、动作逻辑差异更大，适合检验“一底座、多装置”。这是选择建议，不替用户确定下一款。

共用切换演出见 `../shared_base/统一底座与切换演出.md`，尺寸以 `../shared_base/底座尺寸契约.md` 为准。所有动作都需要支持当前姿态接续、重复点击、反向组装与关闭优先；不能用播放固定影片代替可交互机构。旧 A/C/D 的完整动作方向保留在 `../atomic_desktop/方案说明.md`；B 以当前运行源码与测试记录为准。
